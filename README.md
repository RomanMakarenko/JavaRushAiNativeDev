# JavaRush AI-Native Dev — навчальні задачі

Цей репозиторій містить практичні задачі та навчальні матеріали до курсу **AI-Native Dev** від JavaRush.

## Про курс

Курс присвячений сучасному підходу до розробки програмного забезпечення з використанням штучного інтелекту та AI-інструментів. Його мета — сформувати навички AI-native розробника, який уміє ефективно створювати, аналізувати, тестувати, рефакторити й розгортати програмні продукти за допомогою AI.

У межах курсу розглядаються:

- налаштування середовища розробки та робота з Claude Code;
- формулювання технічних задач і керування контекстом за допомогою `CLAUDE.md`;
- аналіз легасі-коду та незнайомих кодових баз;
- використання subagents, MCP і hooks;
- автоматизація розробки, тестування, налагодження та code review;
- проєктування архітектури й рефакторинг;
- робота з GitHub, CI/CD, деплоєм і моніторингом;
- створення власного продукту — від ідеї до перших користувачів;
- підготовка портфоліо та розвиток кар’єри в IT.

## Структура репозиторію

Задачі організовані за рівнями та темами курсу. Кожна директорія може містити вихідний код, тести, конфігураційні файли та додаткові матеріали, необхідні для виконання відповідної практичної роботи.

## Результат навчання

Виконання задач допомагає пройти повний цикл розробки програмного продукту: від постановки задачі та аналізу вимог до реалізації, тестування, перевірки якості й підготовки проєкту до розгортання.
