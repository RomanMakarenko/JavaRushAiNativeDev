# Task spec — refund amount bugfix

## Мета
Часткове повернення замовлення має розраховуватися від фактично списаної суми,
а не від повної ціни замовлення.

## Scope
- Сервіс розрахунку повернення в модулі `refunds`.
- HTTP-ендпоінт ініціювання повернення.

## Non-goals
- Зміна схеми бази даних.
- Зміна клієнтського UI.

## Acceptance criteria
- Часткове повернення не перевищує фактично списану суму.
- Повторне повернення вже повернутого замовлення відхиляється.
