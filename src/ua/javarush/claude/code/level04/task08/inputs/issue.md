# Issue SEARCH-71: порожній запит показує всі suggestions

## Що відбувається
У полі пошуку ShopFlow при порожньому запиті (`query = ""`) випадаючий список
suggestions показує весь каталог, хоча має бути порожнім.

## Очікувана поведінка
При порожньому запиті або запиті, що складається лише з пробілів, список suggestions порожній.

## Задіяний модуль
`com.example.search.SearchSuggestionService` (backend).

## Scope очікуваної зміни
Лише логіка побудови suggestions для порожнього запиту в
`SearchSuggestionService`. Інші модулі завдання не зачіпає.
