# Issue: label замовлення зберігається із зайвими пробілами

## Поточна поведінка
Під час створення замовлення поле `label` зберігається як є, разом із початковими та
кінцевими пробілами. Через це у списку замовлень з'являються дублікати на кшталт
`" Терміновий"` і `"Терміновий"`, які вважаються різними значеннями.

## Бажана поведінка
Початкові та кінцеві пробіли в `label` мають обрізатися перед збереженням.
Внутрішні пробіли зберігаються без змін.

## Зачеплена область
- `OrderLabelService` у модулі `orders`.
