# Уточнювальні запитання та відповіді — Checkout Flow Bug

## 1. Де має бути захист від повторного застосування промокоду?

**Відповідь:** На обох рівнях — UI та сервер.

---

## 2. Як визначити, чи промокод вже застосовано до кошика?

**Відповідь:** Потрібно додати поле до схеми даних, яке фіксує, що код уже застосовано до поточного кошика.

---

## 3. Який статус/повідомлення має бачити користувач після успішного застосування?

**Відповідь:** Текст «Знижка X% застосована», перекреслена стара сума та поряд оновлена сума замовлення.

---

## 4. Що має статися, якщо промокод недійсний / прострочений / вичерпано ліміт?

**Відповідь:** Потрібно додати спливаюче вікно (popup) на UI з повідомленням про помилку.

---

## 5. Який критерій успіху для перевірки виправлення?

**Відповідь:** Написати unit-тест, інтеграційний тест та E2E-тест; існуючі тести також мають проходити.
