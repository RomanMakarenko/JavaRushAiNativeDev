# Баг: помилка оплати на checkout

## Коротко
Частина покупців на кроці оплати отримує помилку, хоча гроші фактично списалися.
Замовлення при цьому залишається у статусі `PAYMENT_FAILED`.

## Симптоми
- У UI показується «Оплата не пройшла, спробуйте ще раз».
- У платіжному шлюзі транзакція позначена як `succeeded`.
- У нашому сервісі статус замовлення не оновлюється.

## Підозра
Щось не так із обробкою payment callback від шлюзу.
Можливо, callback приходить, але ми неправильно мапимо його статус.

## Що просять
Спочатку зібрати недостаючі факти, потім — компактний evidence log. Виправляти поки рано.
