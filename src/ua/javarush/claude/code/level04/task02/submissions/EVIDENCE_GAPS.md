> Зібрано всередині Claude CLI: що ще потрібно, щоб упевнено шукати причину.

1. Який повний набір статусів надсилає провайдер `acme-pay` і як саме `succeeded`
   має мапитися у внутрішній статус замовлення? У коді `succeeded` не обробляється.
2. Чи відтворюється проблема лише для `succeeded`, чи інші статуси теж падають у
   `default -> PAYMENT_FAILED`? Потрібен список статусів із контракту шлюзу.

   callback для `A-20517`, але немає даних про частку втрачених подій.
4. Що відбувається зі статусом замовлення після `PAYMENT_FAILED` — чи є reconciliation-джоба,
   яка пізніше звіряє статус зі шлюзом?
