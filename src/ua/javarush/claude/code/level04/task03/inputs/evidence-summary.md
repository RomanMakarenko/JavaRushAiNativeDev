# Короткий evidence summary

- Ввід `"  Alice  "` зберігається як `"  Alice  "` — пробіли не прибираються.
- Ввід `"Bob"` без пробілів зберігається коректно як `"Bob"` (happy path працює).
- Рядок з самих пробілів `"   "` зараз зберігається як непорожнє ім'я.
- Функція: `update_display_name(name: str) -> str` у `app/profile.py`.
- Compatibility: сигнатура функції та формат значення, що повертається (str), не змінюються.
