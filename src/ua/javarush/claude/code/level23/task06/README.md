# refund-svc

Невеликий сервіс оброблення повернень (refund) платежів.

## Локальний запуск

1. Скопіюйте `.env.example` у `.env` і заповніть реальними значеннями.
2. Запустіть сервіс командою з розділу розробки.

Файл `.env` містить секрети (ключ платіжного шлюзу, JWT secret, рядок підключення до БД)
і не має потрапляти до репозиторію. У git зберігається лише `.env.example` із placeholder-значеннями.
