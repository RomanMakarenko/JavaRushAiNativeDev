# refund-service — release tooling

Сервіс обробки повернень. У каталозі `release/` міститься політика релізного процесу.

## Релізний процес

Реліз відбувається через Layer 3 human approval gate: жодна дія, чутлива до production,
не виконується без явного підтвердження людиною.

- `release/release-policy.yaml` — машиночитувана політика релізу.

Поточний реліз: `v2.31.0` (виправлення черги повернень).
