# Commerce OS

Сервіс керування замовленнями та поверненнями. Локальна розробка ведеться через Docker Compose.

## Поточне завдання

У backlog є ризикована операція: batch-виправлення статусів у черзі повернень
(`refund_queue`). Перед будь-якими діями над даними ізолюємо роботу в окремий
worktree, щоб основна робоча копія не постраждала.

## Структура

- `init.sh` — розгортає git-репозиторій з гілкою `main` (запустіть перед початком)
- `src/` — вихідний код сервісу
- `submissions/` — робочі артефакти поточного завдання
