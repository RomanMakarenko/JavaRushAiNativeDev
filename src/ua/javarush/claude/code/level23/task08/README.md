# Commerce OS

Сервіс керування замовленнями та поверненнями.

## Середовища

- `docker-compose.yml` — середовище для локальної розробки (постійна БД з volume).
- `docker-compose.test.yml` — ізольоване середовище для міграційних експериментів.

Для rehearsal schema migration над таблицею повернень потрібна окрема test DB
з ефемерним сховищем, щоб кожен прогін стартував з чистого аркуша і
легко скидався.
