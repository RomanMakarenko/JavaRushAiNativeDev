# DEMO — сценарій демонстрації

Один потік на 2 хвилини.

1. Запустити сервіс: `./gradlew bootRun`.
2. Показати запит по відомому замовленню:
   `curl "http://localhost:8080/api/demo/refund-summary?orderId=A-1001"`.
3. Прочитати з відповіді статус і причину повернення.
4. Показати обробку невідомого замовлення (404) на `orderId=UNKNOWN`.

Головна думка демо: агент отримує відповідь клієнту одним запитом, без переходу
до billing-панелі.
