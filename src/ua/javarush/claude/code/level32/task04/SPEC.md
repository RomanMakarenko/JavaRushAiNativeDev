# SPEC — Refund Demo Service

## Призначення

Сервіс надає коротку зведену інформацію про повернення коштів для одного замовлення, щоб
сапорт-агент міг відповісти клієнту без переходу до основної billing-панелі.

## Головний сценарій

Агент знає `orderId` з звернення клієнта і запитує по ньому refund summary.

## Контракт API

### `GET /api/demo/refund-summary`

Параметри:

| Параметр  | Тип    | Обов’язковий | Опис                 |
|-----------|--------|--------------|----------------------|
| `orderId` | string | так          | Ідентифікатор замовлення |

Приклад відповіді:

```json
{
  "orderId": "A-1001",
  "amount": 49.90,
  "currency": "EUR",
  "status": "REFUNDED",
  "reason": "duplicate-charge"
}
```

## Поза scope

- Реальна інтеграція з платіжним провайдером.
- Аутентифікація та авторизація агента.
- Історія змін статусу повернення.
