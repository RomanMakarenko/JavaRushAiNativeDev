# EVIDENCE — підтвердження працездатності

## Тести

Запуск:

```bash
./gradlew test
```

Результат: 4 тести, усі зелені. Покрито happy-path запиту refund summary і
випадок невідомого `orderId` (404).

## Ручний прогін demo

```bash
curl "http://localhost:8080/api/demo/refund-summary?orderId=A-1001"
```

Відповідь збігається з прикладом із `SPEC.md`: статус `REFUNDED`, сума `49.90 EUR`.

## Відомі прогалини

- Дані про повернення захардкожені в in-memory-сховищі.
- Немає навантажувального тестування.
