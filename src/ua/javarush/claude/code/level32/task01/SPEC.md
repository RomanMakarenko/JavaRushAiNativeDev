# SPEC — поведінка сервісу

## Ендпоінти

### GET /health
Перевірка працездатності сервісу.

- Код відповіді: `200 OK`
- Тіло відповіді: `{"status":"ok"}`

### GET /tickets/{ticket_id}
Повертає статус заявки підтримки за ідентифікатором.

- Код відповіді: `200 OK`, якщо заявку знайдено.
- Код відповіді: `404 Not Found`, якщо заявки немає.
- Тіло успішної відповіді: `{"id": "...", "status": "..."}`

## Конфігурація

- Порт сервісу задається змінною середовища й прокидається назовні через Docker Compose.
- Значення порту за замовчуванням для локального запуску: `18080`.
