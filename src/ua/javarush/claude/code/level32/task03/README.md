# Сервіс демо-повернення коштів

Невеликий capstone-сервіс, який за ідентифікатором замовлення збирає коротке
зведення щодо повернення коштів: суму, статус і причину повернення.

Сервіс потрібен агенту підтримки, щоб швидко відповісти клієнту, не відкриваючи
основну білінг-панель.

## Запуск

```bash
./gradlew bootRun
```

## Демо-ендпойнт

```bash
curl "http://localhost:8080/api/demo/refund-summary?orderId=A-1001"
```
