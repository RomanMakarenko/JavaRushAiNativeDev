# Основний end-to-end сценарій

## User
Агент підтримки, який має `orderId` зі звернення клієнта та хоче швидко перевірити стан повернення коштів.

## Entry point
Агент запускає сервіс і надсилає HTTP-запит до демо-ендпойнта `GET /api/demo/refund-summary`.

## Steps
1. Агент переходить до робочої директорії сервісу.
2. Агент запускає застосунок командою `./gradlew bootRun`.
3. Після запуску сервісу агент запитує зведення для замовлення `A-1001`.
4. Сервіс знаходить зведення повернення за переданим `orderId`.
5. Агент переглядає суму, валюту, статус і причину повернення у відповіді.

## Commands
```bash
./gradlew bootRun
curl "http://localhost:8080/api/demo/refund-summary?orderId=A-1001"
```

## Expected result
Сервіс повертає JSON-зведення для замовлення `A-1001` із сумою `49.90`, валютою `EUR`, статусом `REFUNDED` і причиною `duplicate-charge`. Агент використовує ці дані, щоб відповісти клієнту без переходу до основної білінг-панелі.
