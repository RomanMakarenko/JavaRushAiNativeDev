# SPEC — Сервіс демо-повернення коштів

## Призначення

Сервіс віддає коротке зведення щодо повернення коштів для одного замовлення,
щоб агент підтримки міг відповісти клієнту без переходу в основну білінг-панель.

## Головний сценарій

Агент знає `orderId` із звернення клієнта і запитує за ним зведення щодо
повернення коштів.

## Контракт API

### `GET /api/demo/refund-summary`

Параметри:

| Параметр  | Тип    | Обов'язковий | Опис                   |
|-----------|--------|--------------|------------------------|
| `orderId` | string | так          | Ідентифікатор замовлення |

Приклад запиту:

```bash
curl "http://localhost:8080/api/demo/refund-summary?orderId=A-1001"
```

Приклад відповіді:

```json
{
  "orderId": "A-1001",
  "amount": 49.90,
  "currency": "EUR",
  "status": "REFUNDED",
  "reason": "duplicate-charge"
}
```

## Поза межами scope

- Реальна інтеграція з платіжним провайдером.
- Автентифікація та авторизація агента.
- Історія змін статусу повернення.
