# task-workspace

Підготовка `Implementation Plan` за issue з сортуванням сповіщень.

У каталозі `inputs/` уже лежать готові артефакти попередніх етапів:
- `ISSUE_INTAKE.md` — розбір вхідного issue.
- `INVESTIGATION_NOTE.md` — результат plan-mode investigation.

Ваше завдання — зібрати повний `submissions/IMPLEMENTATION_PLAN.md`, готовий до затвердження людиною.
