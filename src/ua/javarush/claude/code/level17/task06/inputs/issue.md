# Issue #531: погашення купона відповідає 500 замість помилки валідації

## Проблема
`POST /api/coupons/redeem` іноді повертає `500 Internal Server Error`, хоча
очікується керована відповідь з помилкою валідації.

## Вплив на користувача
Користувач бачить загальну серверну помилку замість зрозумілого повідомлення про те, що
код купона некоректний.

## Відомі докази
- У логах: NullPointerException при `code == null`.
- Відтворення: `POST /api/coupons/redeem` з тілом `{"code": null}`.

## Відкриті питання
- Який error code очікує frontend для некоректного купона?

## Поза межами
- Зміни в логіці знижок.
