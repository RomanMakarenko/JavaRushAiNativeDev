# Нотатка фронтенду

За статусу `500` інтерфейс показує загальний toast і не вміє відрізняти порожній кошик
від інших помилок.

Поточний контракт помилки: `{ "error": "...", "code": "..." }`.
Якщо бекенд змінить статус або формат, потрібно оновити обробку на клієнті.

Напевно, найзручніше отримати `400` із полем `code`, але це треба узгодити.
