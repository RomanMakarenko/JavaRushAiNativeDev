# Лог підтримки

За останні 7 днів — 12 звернень з однаковим сценарієм «порожній кошик → помилка».

Клієнти пишуть, що бачать повідомлення «щось пішло не так» і не розуміють, що робити.
Частина з них іде й не повертається до оформлення.

Можливо, частіше трапляється в мобільному застосунку, але точних метрик немає.
