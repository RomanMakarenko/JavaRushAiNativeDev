# Коментар команди фронтенду

Зараз у відповідь на `500` інтерфейс показує загальний тост «щось пішло не так».

Факт: фронтенд спирається на поточний формат помилки `{ "error": "...", "code": "..." }`.
Якщо backend почне повертати інший статус, потрібно синхронізувати обробку на клієнті.

Можливо, нам підійде `400 Bad Request` із полем `code`, але рішення за бекендом.
