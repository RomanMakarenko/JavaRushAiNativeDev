# Issue #482

Замовлення не оформлюється, якщо кошик порожній.
На фронті показується загальна помилка.

Очікувано: користувач бачить зрозуміле повідомлення про порожній кошик.
Фактично: endpoint `POST /api/orders` повертає `500 Internal Server Error`.
Вплив: покупець не може завершити checkout і не розуміє, що робити.

Ймовірно, треба додати перевірку в `OrderController`.
Скріншот і stack trace прикріплено.
