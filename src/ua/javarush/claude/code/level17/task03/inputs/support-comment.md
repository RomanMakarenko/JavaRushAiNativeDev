# Коментар служби підтримки

За тиждень надійшло 12 звернень з однаковим сценарієм.

Фактично: користувачі скаржаться на «щось пішло не так» під час оформлення порожнього кошика.
Вплив: частина клієнтів іде, не завершивши покупку.

Можливо, проблема відтворюється лише в мобільному застосунку, але це поки що не перевіряли.
Ймовірно, це пов'язано з нещодавнім релізом checkout, точних даних немає.
