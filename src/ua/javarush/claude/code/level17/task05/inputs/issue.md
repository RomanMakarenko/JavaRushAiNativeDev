# Issue #517: повернення купона повертає 500 замість помилки валідації

## Проблема
`POST /api/coupons/return` іноді повертає `500 Internal Server Error` замість
зрозумілої помилки валідації.

## Вплив на користувача
Користувач бачить загальну серверну помилку і не розуміє, що саме пішло не так.
Очікується контрольована відповідь `400` із поясненням.

## Відомі докази
- У логах: NullPointerException при порожньому `couponCode`.
- Відтворення: `POST /api/coupons/return` з тілом `{"couponCode": null}`.

## Відкриті питання
- Який саме код помилки і текст очікує frontend?
- Чи потрібно окремо розрізняти "купон не знайдено" і "купон уже повернуто"?

## Поза межами
- Редизайн сторінки повернень.
- Зміни в логіці нарахування купонів.
