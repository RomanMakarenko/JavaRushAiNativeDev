# task-workspace

Підготовка `Implementation Plan` щодо багу сортування замовлень в API.

У каталозі `inputs/` уже лежать готові артефакти попередніх етапів:
- `ISSUE_INTAKE.md` — розбір вхідного issue.
- `INVESTIGATION_NOTE.md` — результат plan-mode investigation.

Ваше завдання — у Claude Code зібрати `submissions/IMPLEMENTATION_PLAN.md` до будь-яких змін.
