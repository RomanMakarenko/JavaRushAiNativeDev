# CLAUDE.md

Робоча папка для проходження issue-to-PR циклу по тикету про refund flow.

## Контекст проєкту
Бекенд інтернет-магазину на Java/Spring. Точка зміни — `OrderController` і сервіс складу.

## Правила роботи
- Спочатку розбираємо issue і фіксуємо артефакти, лише потім чіпаємо product code.
- Усі проміжні документи складаємо в `submissions/`.
- Вхідні матеріали в `inputs/` вважаємо read-only.
