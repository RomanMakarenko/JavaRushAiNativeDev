# BUG: повернення коштів не зменшує залишок на складі

Під час оформлення refund за замовленням гроші клієнту повертаються, але кількість товару на складі не збільшується назад. Через це залишки в каталозі розходяться з реальністю.

## Як відтворити
1. Створити замовлення на товар `SKU-1024` (2 штуки).
2. Підтвердити замовлення і дочекатися списання зі складу.
3. Виконати refund за цим замовленням через `POST /orders/{id}/refund`.
4. Відкрити картку товару `SKU-1024`.

## Очікувана поведінка
Після refund залишок `SKU-1024` повертається до початкового значення.

## Фактична поведінка
Залишок `SKU-1024` лишається зменшеним, ніби товар досі проданий.

## Зачеплений код
`OrderController.refund(...)` і пов'язаний сервіс складу.
