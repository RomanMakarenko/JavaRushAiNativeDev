# Коментар від QA

Баг відтворюється стабільно на staging. Перевіряли на трьох різних `SKU` — поведінка однакова: гроші повертаються, залишок не зростає.

Підозрюємо, що в обробнику refund викликається лише billing-частина, а повернення на склад просто не викликається. Логів про збільшення залишку в момент refund не видно.

Пріоритет високий: розбіжність залишків уже призвела до двох перепродажів відсутнього товару.
