# Класифікація матеріалів для evidence bank

У `inputs/` зібрано сирий набір матеріалів із роботи над проєктами. Частину з них можна
публікувати як proof-of-work, частину — тільки внутрішньо, частину потрібно санітизувати, а
один файл не можна публікувати взагалі.

Потрібно написати класифікацію в `submissions/EVIDENCE_CLASSIFICATION.md`, щоб внутрішній
робочий лог не змішувався з публічним evidence bank.
