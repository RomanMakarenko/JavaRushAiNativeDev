# Класифікація evidence-матеріалів

Класифікація виконана для матеріалів із `inputs/`. Вхідні файли не змінювалися.

## Можна публікувати зараз

- `inputs/capstone-readme.md` — публічний опис інструмента, стеку та demo; секретних або приватних даних немає.
- `inputs/demo-screenshot-description.md` — опис демонстраційного сценарію без реальних користувачів чи приватних даних.
- `inputs/pr-walkthrough.md` — технічний розбір виправлення з regression test і посиланням на публічний PR; чутливих даних немає.
- `inputs/reviewer-agent.md` — опис багаторазового робочого асета, придатний для публічної демонстрації.

## Тримати лише внутрішньо

- `inputs/internal-retro.md` — містить особисті оцінки учасників і внутрішні процесні деталі, не призначені для зовнішньої публікації.

## Спочатку санітизувати

- `inputs/transcript-snippet.md` — перед публікацією потрібно прибрати або замінити staging URL, робочі шляхи та інші внутрішні деталі з сирого transcript.

## Виключити

- `inputs/leaked-token.txt` — містить облікові секрети (AWS secret та GitHub token); не публікувати й не включати до evidence bank навіть після редагування.
