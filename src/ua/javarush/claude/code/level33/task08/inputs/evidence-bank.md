# Evidence bank

Підтверджені факти про роботу кандидата (лише те, що реально зроблено).

## Capstone
- Проєкт `billing-reliability-lab`: відтворення й усунення бага
  подвійного списання під час retry оплати.
- Написано тест, що відтворює баг, і мінімальну ідемпотентну правку.

## Pull request
- PR із фіксом ідемпотентності списання: додано idempotency_key,
  закрито гонку двох retry-запитів.

## Workflow artifact
- Кастомна команда збору контексту для розслідування бага
  (підтягує релевантні файли та вивід діагностичних команд).

## Що НЕ підтверджено (не використовувати)
- Управління командою, enterprise rollout, production ownership у проді.
