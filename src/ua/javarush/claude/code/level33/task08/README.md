# task-workspace: baseline career package

Тут лежать evidence notes, обраний narrative track і список дозволених
публічних посилань. Із них потрібно зібрати єдиний baseline package.

## Структура
- `inputs/evidence-bank.md` — підтверджені факти (не змінювати).
- `inputs/selected-track.md` — обраний narrative track (не змінювати).
- `inputs/public-links.md` — дозволені публічні посилання (не змінювати).
- `submissions/CAREER_BASELINE.md` — сюди складається результат.

## Що зробити
Створити один markdown-файл із узгодженими блоками для resume, GitHub
і LinkedIn, спираючись лише на evidence та дозволені посилання.
