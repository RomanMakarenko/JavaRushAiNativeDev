# Нотатки про найсильніші сторони

- Упевнено веду задачу повним циклом: issue → plan → implementation → tests →
  review → docs. Це видно повторювано, не як поодинокий епізод.
- Роблю small diff і вмію читати зміни через review trail.
- Пишу reproducible regression tests до фіксу.
- Спокійно працюю з незнайомим кодом через characterization checks.

Слабші сторони: CI/CD, складніші integration tests, архітектурні рішення рівня системи.
