# Evidence bank

Артефакти, накопичені за курс по проєкту Commerce OS і meta-проєкту Workflow Kit.

- `TASK_SPEC.md` (RF-217) — інженерне формулювання задачі про неправильний порядок
  refund-запитів в inbox.
- `PR-walkthrough.md` (RF-217) — повний issue-to-PR: план, small diff, пояснення
  змін, посилання на review.
- `REVIEW_NOTES.md` — нотатки review із знайденими зауваженнями та їхнім закриттям.
- `regression-tests.md` — reproducible тести, що відтворюють баг RF-217 до фіксу.
- `refactor-case.md` — рефакторинг розрахунку кошика з characterization checks,
  поведінка збережена.
- `capstone-README.md` — capstone core flow з інструкцією відтворення.
- `agents-reviewer.md` — чернетка reviewer-agent (один кейс, без team adoption).
- `MIGRATION_PLAN.md` — навчальний pilot migration plan (не доведений до продакшена).
