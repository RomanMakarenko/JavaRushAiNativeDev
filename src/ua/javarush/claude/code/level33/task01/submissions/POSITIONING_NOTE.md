# Professional positioning

## What I own

У проєкті `refund-service` я самостійно визначав вимоги до правила розрахунку повернення, його граничні випадки та критерії перевірки. Я спроєктував правило, написав unit-тести, знайшов і виправив баг із подвійним списанням та підняв покриття тестами з 0 до 64 відсотків.

Я також налаштував прогін тестів через GitHub Actions і описав локальний запуск через `docker-compose` у README. Перед кожним комітом я переглядав diff, перевіряв результати тестів і сам ухвалював рішення щодо якості та готовності змін до merge. Інтеграція з реальним платіжним провайдером залишилася за межами цього capstone: замість неї використовується stub.

## Where Claude helps

Claude Code допомагає мені швидше розібратися в незнайомому коді та залежностях, підготувати чернетки тестів, повідомлень комітів і технічної документації. Я використовую його для investigation, підготовки варіантів і повторюваних документувальних задач.

Claude не визначає вимоги, не замінює моє code review і не ухвалює фінальних рішень. Я формулюю task spec, визначаю потрібні тести, перевіряю diff та результати CI і відповідаю за остаточний результат.
