# Positioning workspace — self-intro

Продовження роботи Артема над публічним позиціонуванням за підсумками capstone-проєкту
`refund-service`. На цьому кроці потрібен короткий self-intro, який одразу показує
інженерне ownership, а Claude Code описують як помічника, а не виконавця.

## Структура

- `inputs/` — нотатки про capstone і workflow плюс список заборонених фраз.
- `submissions/` — позиціонувальна нотатка і trace сесії Claude Code.

## Поточне завдання

У чистій Claude-сесії (розпочатій з `/clear`) підготувати `submissions/POSITIONING_NOTE.md`
з розділами `What I own` і `Where Claude helps`, а потім експортувати trace сесії в
`submissions/SESSION_TRACE.md` через `/export`. Файли в `inputs/` змінювати не можна.
