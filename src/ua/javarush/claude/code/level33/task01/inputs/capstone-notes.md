# Нотатки про capstone

Проєкт: refund-service — сервіс обробки повернень за замовленнями.
Стек: Java, Spring Boot, PostgreSQL, Docker.

Що зробив сам:
- спроєктував правило розрахунку суми повернення та граничні випадки;
- написав unit-тести на розрахунок суми повернення;
- знайшов і виправив баг з подвійним списанням;
- підняв покриття тестами з 0 до 64 відсотків;
- налаштував прогін тестів через GitHub Actions;
- описав локальний запуск через docker-compose у README.

Що залишилося за межами: реальна інтеграція з платіжним провайдером (використовується stub).
