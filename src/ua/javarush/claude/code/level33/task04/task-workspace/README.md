# Збірка публічного PROOF_OF_WORK.md

У `inputs/` лежать короткі entry-заготовки по чотирьох артефактах із різних проєктів:
capstone, commerce PR walkthrough, reviewer-agent і cashflow migration plan. Також є
`sanitization-rules.md` із правилами того, що не можна виносити в публічний документ.

Потрібно зібрати curated `submissions/PROOF_OF_WORK.md` — обмежену кількість сильних записів,
а не дамп усього підряд.
