# Capstone — evidence bank tool

- Domain: developer tooling.
- Проблема: ручна збірка публічного proof-of-work із розрізнених артефактів відбирала час і призводила до витоку приватних даних.
- Зона відповідальності розробника: дизайн фільтрації за visibility, набір обов’язкових секцій, тести на відсутність private fields.
- Роль AI: допомога з чернеткою генератора і тестів під контролем розробника.
- Verification: `pytest` зелений; тест перевіряє, що private записи не потрапляють до збірки.
- Result: інструмент збирає публічний документ лише з дозволених записів.
- Публічне посилання: https://github.com/example/evidence-bank-demo
- Limitations: підтримується лише markdown-вивід; немає UI.
