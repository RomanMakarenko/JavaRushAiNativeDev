# task-workspace: аудит кар'єрних драфтів

Каталог містить три baseline drafts (resume, GitHub profile, LinkedIn About)
для одного кандидата і список заборонених патернів.

## Структура
- `drafts/` — три кар'єрних драфти (не змінювати).
- `inputs/banned-patterns.txt` — патерни placeholders, порожніх посилань та overclaims.
- `submissions/PLACEHOLDER_AUDIT.txt` — сюди складається результат аудиту.

## Що зробити
Термінальними командами зібрати всі проблемні рядки з трьох драфтів
з іменем файлу та номером рядка в `submissions/PLACEHOLDER_AUDIT.txt`.
