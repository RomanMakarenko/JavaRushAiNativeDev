# Interview narratives prep

Робочий простір для підготовки interview-артефакту перед співбесідою.

Контекст: ви захищаєте capstone-проєкт **AI Commerce Growth OS** (модуль refund
inbox, задача RF-217) і готуєте відповідь на запитання «did you build this, or did AI?».

## Структура

- `inputs/capstone-notes.md` — нотатки про проєкт і вашу роль (не редагувати).
- `inputs/follow-up-questions.md` — типові уточнювальні запитання (не редагувати).
- `inputs/limitations.md` — чесні обмеження проєкту (не редагувати).
- `submissions/INTERVIEW_NARRATIVES.md` — сюди покласти готовий артефакт.

## Що потрібно зробити

Зібрати `submissions/INTERVIEW_NARRATIVES.md` з розділами:
`Main answer` (4 опори), `Follow-up answers` (щонайменше 5) і одна `STAR story`
(`Situation`, `Task`, `Action`, `Result`).
