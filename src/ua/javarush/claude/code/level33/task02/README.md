# Positioning workspace — правила позиціонування

Фінальний крок роботи Артема над публічним позиціонуванням за підсумками capstone-проєкту
`refund-service`. Потрібен документ-пам'ятка, який можна перевикористовувати, щоб писати послідовний
текст профілю для GitHub, README і short bio.

## Структура

- `inputs/` — сирий about-блок, список approved phrases і приклади антипатернів.
- `submissions/` — підсумковий документ `POSITIONING_RULES.md`.

## Поточне завдання

Створити `submissions/POSITIONING_RULES.md` — компактний policy-like документ для публічного
опису AI-assisted engineering workflow. Файли в `inputs/` не змінювати.
