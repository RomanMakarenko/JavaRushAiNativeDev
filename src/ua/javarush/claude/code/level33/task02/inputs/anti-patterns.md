# Антипатерни позиціонування

Passive-user wording (автор як пасивний користувач):
- «I just asked AI to build it».
- «AI does the real coding, I mostly watch and prompt».
- «no real coding from my side».

Overclaim (недоведене перебільшення):
- «production-grade system in a weekend».
- «I shipped 50k lines of code in one week».
- «AI built the whole app».

Чому це небезпечно: такі фрази прибирають внесок автора, не мають підтвердження й руйнують довіру
на першому ж уточнювальному питанні на співбесіді.
