# Правила білінгу CashFlow Dashboard (застарілий документ)

> Увага: документ місцями розходиться з фактичною поведінкою коду.
> Source of truth — код і тести, а не цей файл.

## Підписки на паузі

Підписка в статусі `PAUSED` **не входить** в active MRR і не враховується
в щоденному знімку.

(По факту `MrrFormulas.isInActiveSet` залишає підписку на паузі в active set.)

## Повернення

Часткове повернення середини періоду зменшує суму підписки за proration.

## Повторні платежі

Після успішного retry підписка вважається безперервною.
