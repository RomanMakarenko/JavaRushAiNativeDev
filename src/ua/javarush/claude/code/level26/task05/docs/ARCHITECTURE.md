# Architecture (historical)

> Цей документ описує архітектуру CashFlow Dashboard станом на ранній реліз.
> Його давно не оновлювали, і місцями він розходиться з кодом.

## Огляд

CashFlow Dashboard обчислює recurring revenue за підписками і показує дашборд.

## MRR engine

- MRR обчислюється за ВСІМА підписками, включно з TRIAL: триал враховується як майбутній дохід.
- Знижка застосовується ДО нормалізації річних планів до місяця.
- Розрахунок виконується на льоту під час кожного HTTP-запиту до дашборда.

## Subscriptions

- Підписки зберігаються в PostgreSQL через JPA-репозиторій `SubscriptionRepository`.
- Підписки, термін дії яких закінчився, видаляються з БД нічним batch-процесом.

## Scheduling

- Є один scheduled job, який раз на тиждень перераховує аналітику.

- Кешувати знімки MRR у Redis.
