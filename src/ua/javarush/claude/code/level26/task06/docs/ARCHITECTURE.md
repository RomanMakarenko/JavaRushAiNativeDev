# Архітектура (історична)

> Цей документ описує архітектуру CashFlow Dashboard станом на ранній реліз.
> Він давно не оновлювався і місцями розходиться з кодом.

## Огляд

CashFlow Dashboard обчислює recurring revenue за підписками і показує дашборд.

## MRR engine

- MRR рахується за ВСІМА підписками, включно з TRIAL: trial враховується як майбутній дохід.
- Знижка застосовується ДО нормалізації річних планів до місяця.
- Обчислення виконується на льоту під час кожного HTTP-запиту до дашборда.

## Підписки

- Підписки зберігаються в PostgreSQL через JPA-репозиторій `SubscriptionRepository`.
- Прострочені підписки видаляються з БД нічним batch-процесом.

## Планування

- Є один scheduled job, який раз на тиждень перераховує аналітику.

## Плани на майбутнє

- Перенести обчислення MRR в окремий мікросервіс.
- Кешувати знімки MRR у Redis.
