# case-01 — refund sort regression

Завдання: запропонувати regression test для бага в сортуванні заявок refund inbox.
Після виправлення логіки сортування потрібно переконатися, що порядок заявок
не зламався в edge cases (однакова дата, порожній список).

Очікуваний scope: тільки test-файли в `src/test`.
Не можна: правити `RefundService.java`.
Гарний результат: 1-2 тестові сценарії з зрозумілими assertions.
