# Commerce OS — Runbook сервісу refund flow

Цей документ описує, як підняти сервіс refund flow локально для налагодження.

## Локальний запуск

Зібрати образ і запустити контейнер:

```bash
docker build -t commerce-os-refunds .
docker run --rm -p 8080:8080 commerce-os-refunds
```

> Увага: у поточній версії runbook є неправильна команда запуску,
> її виправляють в окремому завданні цього уроку. Тут файл наведено
> як початковий стан, і змінювати його в цьому завданні не потрібно.

## Перевірка працездатності

Після старту контейнера endpoint health має відповідати на порту `8080`.
