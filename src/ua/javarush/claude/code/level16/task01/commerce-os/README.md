# Commerce OS

Навчальний монорепозиторій платформи Commerce OS.

У цій задачі product code не змінюється. Робота йде лише з механізмом
`git worktree`: створення ізольованого паралельного треку та його cleanup.

Скрипт `init.sh` розгортає репозиторій із гілкою `main` і одним базовим
комітом. Запустіть `bash init.sh` (або попросіть Claude Code виконати його)
перед початком роботи.
