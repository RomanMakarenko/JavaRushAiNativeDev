# commerce-os workspace

Тут команда оцінює, чи окуповується advanced AI-workflow на workstream checkout-refund.

## Правила сесії
- Cost signal знімається через `/usage`, стан контексту — через `/status`.
- Якщо в поточній версії CLI назви команд відрізняються, знайди еквівалент через `/help`.
- Нотатки щодо сесії складай у `submissions/`, product code не чіпай.
