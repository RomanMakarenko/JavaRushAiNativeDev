# CLI Commands Used — l16 t08

| Command | Purpose |
|---------|---------|
| `git diff` | View unstaged working-tree changes |
| `git diff --cached` | View staged changes |
| `git log --oneline -5` | Check recent commit history |
| `git diff HEAD~1 --stat` | View files changed in the most recent commit |
| `/diff` | View pending diff of the current working tree |
| `/code-review` | Invoke the code-review skill on the current working diff |
