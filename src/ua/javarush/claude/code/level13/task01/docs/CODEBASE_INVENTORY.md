# Carta codebase — Commerce OS

Внутрішній документ репозиторію. Описує основні модулі сервісу замовлень
і точки входу. Це частина проєкту, а не зовнішнє джерело даних.

## Модулі

- `com.acme.orders.OrderController` — REST-вхід `/api/orders`, приймання запиту на оформлення.
- `com.acme.orders.OrderService` — бізнес-логіка оформлення замовлення та розрахунку суми.

## Точки входу

- `POST /api/orders` — створення нового замовлення.

## Залежності

- Spring Web (REST-контролери).
- Внутрішнє сховище замовлень (заглушка на поточному етапі).

> Цей файл — внутрішній артефакт codebase. Він не підключається через зовнішні
> інтеграції і не належить до зовнішніх систем команди.
