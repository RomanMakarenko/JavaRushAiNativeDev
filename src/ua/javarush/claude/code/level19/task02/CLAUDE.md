# CLAUDE.md — Commerce OS, модуль refunds

## Що це
Сервіс повернення платежів. Основний потік: `RefundController` -> `RefundService` -> `RefundRepository`.

## Як працювати
- Перед написанням тестів спочатку сформулюй коротку стратегію тестування.
- Спочатку важлива поведінка й ризики, потім вибір рівня тестів, і лише потім тестовий код.
- coverage % — слабкий проксі, а не ціль.

## Команди
- Збірка та тести: `./gradlew test`
