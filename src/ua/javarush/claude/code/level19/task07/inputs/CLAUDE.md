# CLAUDE.md — acme/commerce (контекст стратегії тестування)

Проєкт: e-commerce платформа `acme/commerce`.

## Принципи вибору рівня перевірки

- `Smoke` — швидкий вузький сигнал "критичний шлях живий". Дешевий, запускається часто.
- `Regression` — один захисний сценарій на один уже відтворений баг.
- `E2E` — дорогий наскрізний сценарій через UI та зовнішні залежності. Застосовувати
  тільки до по-справжньому критичних шляхів; великий набір нестабільних E2E гірший,
  ніж кілька надійних.

## Правило

Обирай мінімально достатній рівень. Враховуй вартість підтримки тесту і
тип ризику. Якщо E2E не окупається — явно фіксуй рішення "не робити E2E".
