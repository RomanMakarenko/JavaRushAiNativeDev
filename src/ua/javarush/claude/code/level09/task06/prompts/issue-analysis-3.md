# Prompt: розбір вхідного issue (варіант 3)

Третя копія того самого сценарію issue analysis. Хтось скопіював prompt
у новий файл і трохи переписав заголовки. Workflow усе той самий.

## Вхід
- Issue text.
- Скріншот або опис кроків відтворення.

## Процедура
1. Виділити очікувану та фактичну поведінку.
2. Визначити scope і non-goals.
3. Сформулювати acceptance criteria.
4. Описати verification без запуску реалізації.

## Результат
Документ TASK_SPEC з розділами Goal, Scope, Acceptance criteria, Verification.
