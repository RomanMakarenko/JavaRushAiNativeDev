# Нотатка про стиль документації (docs/**)

Ця домовленість стосується лише матеріалів у каталозі `docs/**`. Вона постійно губиться,
бо зберігається у звичайному тексті й ніде не закріплена.

- Кожен markdown-приклад команди має бути виконуваною командою — тим, що реально можна
  скопіювати й виконати, без псевдокоду.
- Усі згадування файлів мають бути явними шляхами (наприклад, `docs/setup.md`,
  `config/extension-choice.yaml`), а не загальними словами на кшталт «конфіг».
- У прикладах не має бути вигаданих прапорців і неіснуючих команд.
- Для кожного how-to-блоку має бути вказано робочий каталог, з якого
  виконуються команди.
