# Workflow Kit

Внутрішній набір робочих процесів поверх монорепо Commerce OS. Тут команда
налаштовує механізми розширення Claude Code: `prompt`, `CLAUDE.md`, `rule`, `skill`,
`subagent`, `MCP`, `hook` і `plugin`.

## Структура

- `inputs/` — вхідні матеріали для вправ (нотатки, списки болючих місць)
- `.claude/` — загальні інструкції та scoped rules проєкту
- `submissions/` — артефакти, які ви готуєте
