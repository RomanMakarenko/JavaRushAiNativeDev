# Правила для документації

## Виконувані команди

Кожна команда в документації **має бути виконуваною** — її можна скопіювати
та вставити в термінал без змін. Заборонено:

- Псевдокод замість команд (`deploy-app.sh` без аргументів).
- Плейсхолдери, що ламають синтаксис (`<your-token>` усередині команди —
  замінюйте на `YOUR_TOKEN` або виносьте в окремий рядок).
- Команди, які потребують ручного редагування перед запуском — якщо це
  неминуче, додайте примітку **# TODO: замініть ... на ...** прямо в команді.

## Формат команд

- Використовуйте блоки коду з мовою `bash` або `shell`.
- Довгі команди розбивайте на `&&` або `\` для читабельності.
- Пояснюйте, що робить команда, у тексті перед блоком коду.

## Актуальність

- Документація має відповідати поточній версії коду.
- Перед комітом переконайтеся, що шляхи, назви файлів і аргументи команд
  існують у репозиторії.
