# COMMAND ORIGINS

Класифікація команд `/help` за походженням у сесії Claude Code.

---

## Built-in session commands

Команди, вбудовані в ядро Claude Code. Доступні в будь-якій сесії, не потребують
додаткових файлів чи налаштувань проєкту.

| Команда | Пояснення |
|---------|-----------|
| `/help` | Показує довідку — вбудована точка входу в CLI. |
| `/clear` | Очищає історію сесії — керування контекстом, частина ядра. |
| `/compact` | Стискає історію для економії токенів — вбудований механізм сесії. |
| `/context` | Показує поточний вміст контексту — діагностика ядра. |
| `/status` | Діагностична команда ядра — стан сесії, використання токенів тощо. |
| `/doctor` | Перевірка справності інсталяції та середовища — вбудована. |

---

## Workflow-style bundled entries

Вбудовані workflows — складніші команди, які постачаються разом із Claude Code
як готові сценарії (багатокрокові агенти або попередньо налаштовані аналізатори).

**Статус видимості:** усі перелічені нижче bundled entries видимі в поточній
установці (присутні у виводі `/help`), тому позначка `not visible in this
installation` не застосовується.

| Команда | Пояснення |
|---------|-----------|
| `/debug` | Інтерактивний дебаґер — вбудований workflow у Claude Code. |
| `/review` | Код-рев'ю робочої директорії — вбудований workflow. |
| `/simplify` | Спільне спрощення коду — вбудований рефакторинговий workflow. |

---

## Project-local entries

Команди, визначені в межах поточного проєкту через механізм `.claude/skills/`.
Не входять до складу Claude Code; доступні лише в цьому репозиторії.

| Команда | Пояснення |
|---------|-----------|
| `/issue-analysis` | Project-local skill у `.claude/skills/issue-analysis/SKILL.md`. Перетворює сирий текст issue на стандартний `TASK_SPEC.md`. |
| `/review-diff` | Project-local skill (файл SKILL.md не знайдено в межах `level09/task04`, але команда задекларована в `/help`). Ймовірно, лежить в іншій гілці `.claude/skills/` цього проєкту. |

---

## Uncertain (не вдалося визначити з наявних даних)

Команди, чиє походження неможливо однозначно встановити без додаткового аналізу
конфігурації проєкту (`.claude/settings.json`, MCP-серверів, hooks).

| Команда | Пояснення |
|---------|-----------|
| `/jira` | Позначена як «Зовнішня інтеграція». Може бути: (1) project-local skill, (2) MCP-сервер, підключений через `settings.json`, (3) зовнішній плагін. У межах `level09/task04` немає файлу SKILL.md або конфігурації, яка б це уточнила. |
