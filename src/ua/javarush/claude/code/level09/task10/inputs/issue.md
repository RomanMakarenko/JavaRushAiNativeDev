# RF-217: запити на повернення йдуть у inbox у неправильному порядку

## Симптом
Оператор підтримки відкриває inbox повернень у Commerce OS і бачить, що
запити відсортовані не за пріоритетом. Старі термінові повернення падають вниз
списку, а свіжі низькопріоритетні опиняються зверху.

## Де помічено
Модуль підтримки, екран `Refund Inbox`. Список надходить із бекенда вже
відсортованим, фронтенд порядок не змінює.

## Очікувана поведінка
Спочатку йдуть запити з високим пріоритетом, усередині одного пріоритету —
від найстаріших до найновіших (за датою створення).

## Додатково
Схоже, проблема в серверному сортуванні. Підозрілі файли — десь
поруч зі словом `refund` у модулі підтримки.
