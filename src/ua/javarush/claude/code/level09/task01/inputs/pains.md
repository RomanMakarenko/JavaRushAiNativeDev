# Workflow-болі команди Workflow Kit

Нижче наведено вісім повторюваних ситуацій. Кожну потрібно закрити одним механізмом
розширення Claude Code.

1. Щоразу під час розбору нового issue вручну пишемо один і той самий довгий prompt:
   прочитати issue, знайти затронуті модулі, зібрати чорновик TASK_SPEC. Текст
   практично не змінюється від задачі до задачі.

2. Для коду в каталозі `payments/**` діє жорстка межа: заборонено broad refactor
   поруч із refund logic. Це стосується тільки платіжного модуля, не всього репозиторію.

3. Потрібно регулярно підтягувати дані із зовнішнього Jira: статус тікета, коментарі,
   пов'язані задачі. Зараз розробник копіює їх у чат вручну.

4. Після кожного редагування файла хочеться автоматично запускати форматер,
   щоб не ловити diff через стиль на рев'ю.

5. Важке investigation по заплутаному route займає багато кроків і засмічує основний
   контекст сесії: потрібно окреме ізольоване розслідування з коротким звітом.

6. Є загальна інструкція для всього проєкту: завжди показувати план до правок і тримати
   working tree чистим перед AI-assisted edits.

7. Одноразово, один раз, потрібно перейменувати змінну в одному файлі — звичайна дрібна правка,
   повторювати її не плануємо.

8. Хочемо роздати команді єдиний готовий набір: правила + пара skills + налаштування в одному
   пакеті для встановлення, щоб новий розробник підключив усе одразу.
