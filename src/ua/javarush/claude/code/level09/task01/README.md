# Workflow Kit

Внутрішній набір робочих процесів поверх монорепозиторію Commerce OS. Тут команда
налаштовує механізми розширення Claude Code: `prompt`, `CLAUDE.md`, `rule`, `skill`,
`subagent`, `MCP`, `hook` і `plugin`.

## Структура

- `inputs/` — вхідні матеріали для вправ (списки болів, нотатки)
- `submissions/` — артефакти, які ви готуєте
