# Issue REF-204: повернення без коментаря потрапляє в manual review

## Що відбувається
Оператор може відправити повернення на ручну перевірку (manual review),
не заповнивши коментар. У чергу потрапляють порожні картки, рев'юер
не розуміє причину повернення.

## Чого хочемо
Заборонити manual review без непорожнього коментаря оператора.

## Обмеження
- Правка лише на сервісному шарі в цій сесії.
- Інтеграцію контролера виносимо в окремий крок.
