# Специфікація задачі REF-204

## Мета
Повернення в режимі manual review потребує непорожнього коментаря оператора.

## Обсяг
- `RefundService.canRefund(...)` — додати перевірку коментаря.
- Unit-тест на сценарій з порожнім коментарем.

## Не входить
- Controller integration test.
- Кейс `amount > 1000` (окремий ризик).

## Критерії приймання
- Якщо `manualReview = true` і коментар порожній, повернення заборонено.
- `./gradlew test --tests "*RefundService*"` успішно проходить.
