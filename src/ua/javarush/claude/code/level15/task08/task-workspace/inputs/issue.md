# Issue ORD-548 — винести експорт замовлень в окремий модуль

Тип: STRUCTURAL
Модуль: orders
Пріоритет: medium

## Контекст

`OrderExportController` тягне на собі всю CSV-логіку і поступово став
«швейцарським ножем на стероїдах». Потрібно винести експорт замовлень в окремий
модуль `orders/export`, щоб контролер лише приймав запит і делегував
збирання CSV сервісу.

## Що потрібно

- Новий модуль: `orders/export`.
- Межа: контролер приймає запит, CSV збирає `ExportService`.
- Не чіпаємо: `payments/`, `support/`, публічний URL `/api/orders/export`.

## Перевірка

```
./gradlew test --tests "*OrderExport*"
```
