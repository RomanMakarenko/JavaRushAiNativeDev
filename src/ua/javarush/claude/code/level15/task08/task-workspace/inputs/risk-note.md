# Ризики задачі ORD-548

- Це структурна задача: проблема не в одному `if`, а в тому, де проходить
  межа відповідальності. Високий ризик scope creep — спокуса «раз я вже тут,
  заодно поправлю сусідній пакет».
- Не можна зламати контракт публічного URL `/api/orders/export`.
- Сусідні області (`payments/`, `support/`) не мають зачіпатися.

Висновок: потрібна роль, яка заздалегідь зафіксує межу і контракт, та незалежна
перевірка, що межу справді дотримано.
