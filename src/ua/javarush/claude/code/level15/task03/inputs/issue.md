# COM-512 — Доопрацювання потоку замовлень

Потрібно розширити потік замовлень у Commerce OS: додати серверну обробку
нового фільтра, оновити інтерфейс замовлень і закрити тестове покриття.

Контекст:
- API-контракт за фільтрами замовлень уже зафіксовано й заморожено.
- Backend-частина живе в `src/api/orders/*`.
- Frontend-частина живе в `src/web/orders/*`.
- Тести потоку замовлень лежать окремо в `tests/orders/*` і запускаються незалежно.

Розмір роботи: large (кілька файлів у трьох незалежних зонах).
