# CLI Discovery: management surface для agents/sessions

**Знайдена команда:** `claude agents`

**Джерело:** розділ `Commands → agents` у `/help`

**Яку задачу розв'язує:** управління фоновими (background) агентами та перегляд активних
сесій (interactive + background). Цей surface стає потрібним з моменту запуску
другого паралельного workstream — коли кількість активних агентів перевищує
можливість тримати їх у голові.

**Ключові опції:**

| Опція | Призначення |
|------|------------|
| *(без прапорів)* | Відкриває інтерактивний перегляд agents |
| `--json` | Список активних сесій (interactive + background) у JSON (для скриптів) |
| `--all` | Разом із `--json`: також показує завершені background-сесії |
| `--cwd <path>` | Фільтр за робочою директорією |
| `--agent <agent>` | Агент за замовчуванням для сесій із цього перегляду |
| `--model <model>` | Модель за замовчуванням для диспетчеризованих сесій |

**Як використовувати:**

```bash
claude agents                    # інтерактивний перегляд
claude agents --json             # JSON-список активних сесій
claude agents --json --all       # JSON-спив усіх сесій (включно з завершеними)
claude agents --cwd .            # тільки сесії з поточної директорії
```

**Додатково:** `--bg` / `--background` запускає сесію як фоновий агент, яким потім
можна керувати через `claude agents`.
