# Issue ORD-512 — винести CSV-експорт замовлень в окремий сервіс

Тип: STRUCTURAL
Модуль: orders
Пріоритет: medium

## Контекст

Контролер експорту замовлень зараз сам збирає CSV: формує заголовки,
склеює рядки, екранує значення. Через це `OrderExportController`
перетворився на «швейцарський ніж на стероїдах».

## Що потрібно

Перенести CSV-логіку в `OrderExportService`, щоб контролер тільки приймав
запит і делегував збірку сервісу. Публічний URL `/api/orders/export` змінювати
не можна.

## Що відомо про область

- Область змін уже зрозуміла: пакет `com.acme.orders`.
- Для сервісу вже є тест `OrderExportServiceTest`.
- Глибокого discovery всього проекту не потрібно — це акуратна зміна в
  відомій зоні з готовою перевіркою.

## Межі

- Не чіпати публічний URL `/api/orders/export`.
- Не змінювати контракт відповіді (формат CSV).

## Перевірка

```
./gradlew test --tests "*OrderExport*"
```
