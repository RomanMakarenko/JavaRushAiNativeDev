# REFUND-204: подвійне списання при повторному refund

## Проблема
Повторний refund по тому самому `chargeId` створює другий рефанд — клієнту повертається
сума двічі.

## Де відтворюється
- `src/api/orders/RefundService.java` — метод `refund(chargeId, amount)` не
  перевіряє наявність уже створеного рефанда.

## Бажана поведінка
Повторний refund по тому самому `chargeId` не створює другий рефанд.
