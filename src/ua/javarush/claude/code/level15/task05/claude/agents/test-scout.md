# Test-scout (розвідка тестів)

Роль `test-scout` досліджує тестове покриття refund flow.

Що робить:
- знаходить наявні tests, пов’язані з порядком refund-запитів;
- відзначає прогалини в покритті;
- фіксує посилання на тестові файли.

Що НЕ робить:
- не пише нові tests у межах investigation;
- не править код;
- працює в режимі read-only investigation.
