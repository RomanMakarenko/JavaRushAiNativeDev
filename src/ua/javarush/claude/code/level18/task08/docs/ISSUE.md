# issue-432: порожній кошик призводить до 500 замість 400

## Поточна поведінка
Запит `POST /api/orders` з порожнім списком позицій (`items: []`) повертає
`500 Internal Server Error`. У логах видно падіння під час спроби обчислити суму
замовлення для порожнього списку.

## Очікувана поведінка
Порожній кошик — це помилка клієнта. Ендпоінт має повертати
`400 Bad Request` із зрозумілим тілом відповіді `Cart is empty`, не доходячи до обчислення суми.

## Зачеплена зона
- Модуль `orders`, клас `OrderController`.

## Поза scope
- Повідомлення про невалідну кількість (`quantity <= 0`) обробляються окремим issue.
- Зміни схеми API та контрактів відповіді для непорожнього кошика не плануються.
