# Issue: checkout падає з 500 при порожньому кошику

Заголовок: Оформлення замовлення повертає 500 замість 400 для порожнього кошика

Середовище: orders-service, гілка main, профіль test

Що відбувається:
Під час надсилання `POST /api/orders/checkout` з тілом `{"items":[]}` сервіс
повертає HTTP 500 Internal Server Error. Очікувався HTTP 400 із зрозумілим
повідомленням "cart is empty".

Як відтворити:
1. Запустити orders-service.
2. Надіслати запит на checkout з порожнім списком items.
3. Отримати 500 замість 400.

Частота: відтворюється стабільно для будь-якого запиту з items=0.

Вплив: клієнт із порожнім кошиком отримує незрозумілу помилку 500;
у логах з'являється stack trace, моніторинг фіксує зростання 5xx.
