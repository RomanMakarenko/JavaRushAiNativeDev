# Поточна конфігурація reviewer skill (витяг)

Артефакт: `.claude/skills/reviewer/risk-rules.md`

Правило класифікації ризику (як зараз):

```
Якщо змінений шлях починається з `src/main/java/com/example/commerce/refunds/`
АБО містить слово `payment` АБО `billing`
=> severity = HIGH (завжди).
```

Коментар:
- Правило спрацьовує лише за шляхом, без урахування розміру diff і наявності тестів.
- Поріг було додано давно «щоб нічого не пропустити» в платіжних потоках.
