# Skill: issue-analysis

Personal skill, який допомагає розібрати сирий issue у структуровану
постановку: `Goal`, `Scope`, `Non-goals`, `Verification`.

- Owner: Andrey (platform team)
- Поточний статус: personal, використовується автором і парою колег вручну.
- Спосіб вимкнення: skill лежить у `.claude/skills/issue-analysis/`, видаляється
  видаленням каталогу.

Запит команди: просунути skill у shared Workflow Kit, але акуратно — спочатку
обмеженим пілотом, без переведення всієї команди разом.
