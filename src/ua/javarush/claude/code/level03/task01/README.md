# Task workspace — tiny spec через Claude CLI

У `inputs/raw-request.md` лежить однорядковий запит на виправлення описки.

Відкрийте Claude Code в корені проєкту, потім
попросіть Claude зібрати компактну постановку задачі в `submissions/TINY_SPEC.md`.
Файли застосунку чіпати не потрібно — на цьому кроці потрібен лише tiny spec.
