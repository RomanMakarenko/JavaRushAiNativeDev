# Звіт про баг (як надійшов від підтримки)

Відкриваю картку повернення, у якої немає нотатки, і одразу отримую білий
екран, працювати з карткою неможливо. Це явно через те, що компонент
лізе в `note.text`, коли нотатки немає — мабуть, забули перевірку на null.
Насправді має бути так: якщо нотатки немає, показуємо `No note provided`,
а якщо нотатка є — її текст, і ніяких крашів. У консолі при цьому висить
`TypeError: Cannot read properties of null (reading 'text')`. Думаю, це
виправляється за п'ять хвилин, найімовірніше достатньо однієї умови в рендері.
