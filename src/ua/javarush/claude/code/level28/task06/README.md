# CashFlow migration — інструменти для пошуку документації

Цей каталог містить конфігурацію інструментів для дослідження, керованого changelog, під час міграції CashFlow на Spring Boot 3.x.

## Локальний docs MCP server

У `tools/local-docs-mcp.sh` лежить локальний stdio-сервер для пошуку в офіційній документації. Він використовується ЛИШЕ для пошуку (read-only) і не повинен виконувати правки коду, build або version bump.

## Завдання

Файл `.mcp.json` поки порожній. Потрібно підключити сервер `spring-docs`, який вказує на `tools/local-docs-mcp.sh`, у режимі read-only.
