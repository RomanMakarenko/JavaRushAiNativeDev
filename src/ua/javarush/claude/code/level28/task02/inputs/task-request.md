# Запит на зміну legacy-сервісу

Нам потрібно нарешті зрушити CashFlow Dashboard з мертвої точки.

1. Оновити Spring Boot з 2.7 до 3.x і Java з 8 до 21. Старий `javax.persistence`
   у новій версії не працює — доведеться переїжджати на `jakarta.persistence`.
2. Раз уже ліземо в код — почистити `BillingService`, там накопичився мотлох і дублювання.
3. І ще дратує, як обчислюються timestamps у звітах: треба нормалізувати часові мітки
   до єдиного часового поясу.

Хочеться все це зробити одним заходом.
