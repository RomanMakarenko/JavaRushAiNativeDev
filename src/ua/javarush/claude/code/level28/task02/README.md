# CashFlow Dashboard

Сервіс обліку підписок і грошових потоків. Поточний стек — Spring Boot 2.7, Java 8.

Команда готує переведення проєкту на сучасний стек, але вхідні запити часто
змішують кілька типів роботи в одному тексті. Це завдання — про визначення
основного режиму роботи, без написання коду.
