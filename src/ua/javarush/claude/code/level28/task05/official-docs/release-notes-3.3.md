# Spring Boot 3.3 Release Notes (локальна копія)

## Jakarta

- Завершено перехід екосистеми на простір імен `jakarta.*`.
  Будь-які залишкові імпорти `javax.persistence` / `javax.validation` вважаються
  помилкою сумісності.

## Configuration

- Додаткові зміни ключів конфігурації; застарілі ключі логують
  попередження під час запуску.

## Java

- Підтверджено Java baseline 17+; рекомендується Java 21 для довгострокової підтримки.
