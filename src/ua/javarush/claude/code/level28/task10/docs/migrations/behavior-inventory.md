# Інвентаризація поведінки — сервіс cashflow

Спостережувані behaviors (не імена класів), які сервіс демонструє сьогодні.

1. `GET /api/v1/subscriptions/{id}` повертає 200 із підпискою, 404 за її відсутності.
2. `GET /api/v1/subscriptions` повертає список підписок.
3. Дати в JSON-відповідях серіалізуються в ISO-8601 у зоні UTC.
4. Бізнес-помилки повертаються як стабільні коди (`BILLING_ACCOUNT_SUSPENDED`, `SUBSCRIPTION_NOT_FOUND`).
5. Невалідний або відсутній токен призводить до 401.
6. Health endpoint повертає статус UP.

Ці behaviors споживач і тести вважають контрактом — вони не повинні змінитися після міграції.
