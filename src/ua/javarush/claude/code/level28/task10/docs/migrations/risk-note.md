# Примітка щодо ризиків — міграція cashflow

Коротка записка щодо ризиків перед складанням плану.

- Spring Security 6 переписує filter chain — ризик змінити поведінку 401.
- javax → jakarta зачіпає всі сутності та валідацію — ризик регресії мапінгу.
- Flyway 9: немає підтвердженого evidence, що міграції V1..V12 застосовуються без змін.
- Серіалізація дат в UTC має залишитися незмінною — її парсить downstream-інтеграція.
- Бізнес-логіку білінгу в межах міграції не чіпаємо.

Частина ризиків уже прийнята командою, частина залишається невирішеною (див. compatibility evidence).
