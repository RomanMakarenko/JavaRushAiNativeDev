# Issue: плаваюча помилка в refund flow

## Що відбувається
Частина покупців скаржиться, що повернення грошей за замовлення іноді «зависає»: статус повернення
не оновлюється, хоча гроші в кабінеті Stripe уже повернено. Відтворюється нестабільно —
приблизно один випадок із десяти, частіше в години пікового навантаження.

## Де помічено
- Модуль повернень `com.example.shop.refunds`.
- Підозра на розсинхронізацію між публікацією події повернення та її обробкою.

## Що вже відомо
- Гроші через Stripe повертаються коректно в усіх випадках.
- Подія про повернення публікується в чергу, але споживач події іноді її не отримує.

## Чого НЕ потрібно робити в межах розслідування
- Змінювати код, конфігурацію або тести.
- Переписувати платіжну інтеграцію.

## Очікуваний результат розслідування
Короткий brief, який обмежує майбутню роботу та фіксує, у якому форматі має бути
повернуто підсумок investigation.
