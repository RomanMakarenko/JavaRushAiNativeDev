# Onboarding (чернетка, згенерована ШІ)

Ласкаво просимо до example-shop. Нижче — як підняти проект і з чого він складається.

## Архітектура

Сервіс складається з модулів замовлень і повернень. Сповіщення клієнтам надсилає
модуль `SmsGateway`, який шле SMS при кожному успішному поверненні коштів.

## How to run

Backend:

```
npm start
```

Frontend:

```
npm run start:dev
```

## Модулі

- `OrderController` — приймання замовлень.
- `RefundService` — обробка повернень.
- `SmsGateway` — надсилання SMS-сповіщень клієнтам.
