# Recovery Decision

## Symptoms

- Асистент починає роботу над багом **auth refresh** (рядки 1–4), але потім двічі визнає помилку в діагнозі й змінює напрямок (рядки 5–6, 9–10).
- Користувач відволікається на **SSO / SAML** (рядок 7) і **refund flow docs** (рядок 11). Асистент підхоплює обидві теми замість того, щоб одразу повернутися до задачі (рядки 8, 12). Хоча він згодом каже «це не наше завдання» (рядок 13), два повноцінні відгалуження вже відбулися.
- Після всіх відволікань асистент усе-таки знаходить корінь — помилку в `refreshIfNeeded()` (рядок 14) — **але сесія містить шумові обміни (13 реплік замість 4–5 необхідних)**, що ускладнює повернення й підвищує ризик repeat-помилок у разі продовження.

## Diagnosis

**Context pollution**

Транскрипт показує класичне забруднення контексту: початковий фокус (auth refresh) був знайдений, але асистент зробив щонайменше **дві хибні гіпотези** («refresh token не зберігається», «scope не збігається»), а користувач додав **дві сторонні теми** (SSO, refund docs). Хоча фінальне рішення коректне, історія діалогу перенасичена — у ній залишилися сліди нерелевантних розвідок (SAML, строки повернення, storage-шар), які спотворюють подальші відповіді моделі. Це не брак контексту (потрібний файл `task-spec.md` явно містить усі необхідні межі та нецілі), а надлишок контексту — *pollution*.

## Chosen action

`/compact`

## Why not the others

| Action | Reason it is NOT the first choice |
|---|---|
| `/clear` / fresh session | Втрачається вже знайдене правильне рішення (рядок 14) та специфікація `task-spec.md`. Для цієї задачі достатньо скинути шум, а не починати з нуля. |
| `/rewind` | Потребує точного рядка для відмотки. Якщо відмотати до рядка 1 — втратиться рішення. Якщо до рядка 14 — залишиться більшість шуму. Жодна проміжна точка не відокремлює pollution від фінального діагнозу чисто. |
| **`/compact`** | Усуває забруднення (SAML, refund docs, хибні гіпотези), але зберігає специфікацію задачі та знайдене рішення. Це єдина дія, яка видаляє шум, не викидаючи корисний результат. |
