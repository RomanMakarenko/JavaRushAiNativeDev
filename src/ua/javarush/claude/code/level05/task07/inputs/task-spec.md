# Специфікація задачі — auth refresh не спрацьовує після спливу токена доступу

## Мета
Виправити оновлення токена доступу: після спливу токена доступу користувача не повинно
викидати на login, якщо refresh token дійсний.

## Обсяг
- `AuthService.refreshIfNeeded()`
- `AuthService.getActiveToken()`
- unit-тест на граничну умову спливу токена.

## Нецілі
- SSO / SAML і модуль `sso-gateway`.
- Документація щодо refund flow (`docs/refund-flow.md`).
- Будь-які зміни у storage-шарі, якщо корінь проблеми не там.

## Критерії прийняття
- При простроченому токені доступу і дійсному refresh token сесія подовжується без login.
- Є тест на граничне значення `expiry == now`.
