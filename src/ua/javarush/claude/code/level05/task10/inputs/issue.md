# Проблема #482: вхід не працює у користувачів із простроченим refresh token

## Суть
Користувачі, у яких сплив refresh token, бачать порожній екран замість
перенаправлення на сторінку входу.

## Як відтворити
1. Успішно увійти в систему.
2. Дочекатися, поки закінчиться TTL refresh token (або завершити його вручну).
3. Зробити будь-який запит, що потребує авторизації.

## Очікується
Користувача перенаправляє на `/login` із повідомленням «session expired».

## Насправді
Застосунок рендерить порожній екран; у консолі —
`TypeError: cannot read 'token' of null` у `src/auth/session.js`.

## Зачеплена область
- `src/auth/session.js` — обробка refresh token і null-session

## Примітки
- Не чіпати refund flow і billing-документацію в цій session.
