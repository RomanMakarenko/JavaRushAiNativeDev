# CLAUDE.md — Commerce OS (auth-модуль)

## Про проєкт

Commerce OS — backend на Java 25 + Spring Boot 4. Цей workspace обмежений
auth-шаром: вхід, валідація облікових даних і відображення форми логіну.

## Правила роботи

- Змінюй лише те, що стосується поточного завдання з `TASK_SPEC.md`.
- Не чіпай public API сесійного шару без явної потреби.
- Не додавай нові зовнішні залежності.
- Перед зміною коду читай `TASK_SPEC.md` і зачеплені файли.

## Команди перевірки

- `./gradlew test` — запуск тестів модуля.
- `./gradlew test --tests AuthFlowTest` — лише auth-сценарії.
