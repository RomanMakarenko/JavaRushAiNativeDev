# Task spec: порожній екран після неправильного пароля

Ціль: виправити порожній екран після неправильного пароля під час входу в Commerce OS.
Наразі користувач замість зрозумілої помилки бачить білу сторінку.

Область змін: `src/auth/*`, `tests/AuthFlowTest.java`.

Обмеження:
- не змінювати public API session-сервісу;
- не чіпати міграції бази даних;
- не додавати нові зовнішні залежності.

Критерії приймання:
- користувач бачить повідомлення про помилку після неправильного пароля;
- успішний логін і далі працює як раніше.
