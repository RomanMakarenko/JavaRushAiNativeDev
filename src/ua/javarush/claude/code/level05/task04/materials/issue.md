# AUTH-318 — сесія скидається після refresh-токена

Після оновлення access-токена приблизно в 5% випадків користувача викидає
на екран входу. Підозра на гонку під час ротації токена в `SessionService`.

Зачеплено: модуль auth (`LoginController`, `SessionService`).
Відтворюється одразу після refresh при паралельних запитах.
