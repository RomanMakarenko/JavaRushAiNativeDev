# Task spec: порожній екран після неправильного пароля

Мета: виправити порожній екран після неправильного пароля під час входу в Commerce OS.
Зараз користувач замість зрозумілої помилки бачить білу сторінку.

Область змін: `src/auth/*`, `tests/AuthFlowTest.java`.

Обмеження:
- не змінювати public API session-шару;
- не чіпати міграції бази даних;
- не додавати нові зовнішні залежності.

Приймання:
- користувач бачить повідомлення про помилку після неправильного пароля;
- успішний логін продовжує працювати як раніше.
