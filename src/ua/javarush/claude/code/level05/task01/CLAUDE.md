# CLAUDE.md

Проєкт: AI Commerce Growth OS (Commerce OS).

## Команди проєкту

- Команда тестів: `./gradlew test`

## Правила

- Не змінювати public API в `src/auth/*`.
- Не чіпати каталог `migrations`.
- Перед правками — перелічити затронуті файли.

## Як Claude працює з контекстом

- Claude пам’ятає всі минулі бесіди в цьому репозиторії, тому переказувати
  вчорашнє розслідування не потрібно.
- Claude автоматично знає вміст усіх файлів проєкту, навіть якщо вони не були
  відкриті в поточній session.
- Після старту нової session проєктні інструкції з цього файлу втрачаються, і їх
  доводиться диктувати заново вручну.
