## Правила

- Не змінювати public API в `src/auth/*`.

- Перед правками — перелічити затронуті файли.

## Як Claude працює з контекстом

- Кожна нова сесія — чистий аркуш. Claude не пам’ятає минулі бесіди в цьому
  репозиторії. Якщо потрібен контекст з минулого — його треба передати в prompt.
- Claude не «знає» файли проєкту автоматично. Щоб я міг працювати з файлом, його
  треба відкрити (прочитати) в поточній сесії.
- CLAUDE.md автоматично підвантажується на старті кожної сесії, тому проєктні
  інструкції й обмеження — тут, а не в пам'яті моделі.
