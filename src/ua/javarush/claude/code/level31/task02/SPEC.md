# SPEC — landing-optimizer-mini

## Поточний release slice

Один надійний сценарій для демо:

1. Користувач вводить URL лендінга в поле введення.
2. Користувач натискає кнопку `Analyze`.
3. Застосунок показує короткий звіт за введеною адресою.

## Заморожений scope

- У демо показуємо лише ланцюжок «ввід URL → аналіз → звіт».
- Жодних нових інтеграцій, авторизації та експорту в цьому slice.

## Відома проблема (наступний slice)

Кнопка `Analyze` зараз активна навіть за порожнього поля URL. Це потрібно
виправити невеликим diff: кнопка має бути неактивною, поки поле порожнє
або містить лише пробіли.
