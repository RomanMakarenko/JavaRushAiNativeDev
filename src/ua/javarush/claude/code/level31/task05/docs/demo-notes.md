# Нотатки до demo

## Що показуємо

Один наскрізний сценарій: користувач вводить URL лендінгу, натискає «Перевірити»,
отримує звіт зі списком зауважень (немає H1, порожній meta description, зображення без alt).

## Demo path (semantic)

1. Відкрити локальний білдіз `dist/` через `npm run build`.
2. Ввести sample URL із `docs/sample-url.txt`.
3. Дочекатися звіту й показати щонайменше три типи зауважень.
4. Показати, що для «чистої» сторінки список зауважень порожній.

## Відтворюваність

- Demo проходить строго на sample URL — без звернення до зовнішніх сайтів у реальному часі.
- HTML sample-сторінок лежить локально в `test/fixtures/`, мережа не потрібна.
- Прогін детермінований: однаковий вхід дає однаковий звіт.

## Що поки НЕ готово

- Немає авторизації та збереження історії перевірок.
- Немає реального fetch довільного URL з інтернету (тільки локальні фікстури).
- Евристик усього чотири, серйозного SEO-аудиту немає.
- UI чорновий, мобільна верстка не перевірялася.
