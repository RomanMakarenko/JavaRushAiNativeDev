# Demo Quality Gate

Короткий чекліст перед повторним demo для локального інструмента аудиту лендінгів.

## Layer 1 — local checks

- [ ] `npm install` завершився без помилок у поточному робочому каталозі.
- [ ] `npm run lint`, `npm run build` і `npm test` завершилися успішно.
- [ ] `npm run smoke` успішно виконав короткий smoke-прогін на sample URL.

## Layer 2 — semantic demo path

- [ ] Запустити demo на локальному білді: виконати `npm run build`, відкрити `dist/` і ввести URL із `docs/sample-url.txt`.
- [ ] Перевірити, що звіт показує щонайменше три очікувані типи зауважень: відсутній H1, порожній meta description і зображення без alt.
- [ ] Показати чисту sample-сторінку та підтвердити, що список зауважень порожній.
- [ ] **Reproducibility:** використовувати лише локальні sample-дані з `test/fixtures/`; повторний прогін з тим самим входом має дати той самий звіт без мережі.

## Layer 3 — honest limitations

- [ ] **Known limitations:** зафіксувати перед demo, що інструмент не має авторизації, збереження історії та реального fetch довільних URL з інтернету.
- [ ] Не називати результат повним SEO-аудитом: перевіряються лише чотири евристики.
- [ ] Не робити висновків про мобільну якість UI: мобільна верстка ще не перевірялася.
