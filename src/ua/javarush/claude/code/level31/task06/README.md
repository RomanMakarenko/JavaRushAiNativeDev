# landing-audit-web

Потужна платформа для повного SEO- та UX-аудиту будь-яких лендінгів. Аналізує сайти,
надає вичерпний звіт про якість і допомагає підвищити конверсію. Готова до
використання в продакшені.

## Можливості

- Повний аудит будь-якого сайту за URL
- Глибокий SEO-аналіз і рекомендації
- Масштабована обробка тисяч сторінок
- Готова інтеграція в CI/CD

## Локальний запуск

```bash
npm install
npm run build
npm test
```

## Команди

- `npm run lint` — статична перевірка `src/`
- `npm run build` — збірка статичного бандла в `dist/`
- `npm test` — модульні тести евристик аудиту
- `npm run smoke` — короткий smoke-прогін аудиту на тестовому URL
