# landing-audit-web

Навчальний demo-інструмент для перевірки одного лендінгу за фіксованим набором
SEO-евристик. Проєкт не є комерційним продуктом і не заявляє production-ready рівень.

## Демо-готовий обсяг

Основний сценарій відповідає `SPEC.md`:

1. Користувач вводить один URL лендінгу.
2. Інструмент бере HTML-сторінку з локальної фікстури `test/fixtures/`.
3. Запускаються чотири евристики: наявність H1, заповнений `<title>`, непорожній
   meta description і наявність `alt` у зображень.
4. Повертається короткий звіт зі списком знайдених зауважень.
5. Для валідної сторінки список зауважень порожній.

Цього обсягу достатньо для локальної демонстрації повного проходу: від введення URL
до отримання результату аудиту на підготовленій HTML-фікстурі.

## Відомі обмеження

- Перевіряється лише один URL за один запуск.
- HTML не завантажується з інтернету: джерелом сторінки є локальна фікстура з `test/fixtures/`.
- Набір перевірок фіксований і містить лише чотири евристики: H1, `<title>`, meta description та `alt` для зображень.
- Розширення набору евристик або додавання власних правил у демо не передбачене.
- Авторизації користувачів, бази даних і збереження історії перевірок немає.
- Інструмент повертає короткий список зауважень, а не повний SEO- та UX-звіт із рекомендаціями.

## Локальний запуск

```bash
npm install
npm run build
npm test
```

## Команди

- `npm run lint` — статична перевірка `src/`
- `npm run build` — збірка статичного бандла в `dist/`
- `npm test` — модульні тести евристик аудиту
- `npm run smoke` — короткий smoke-прогін аудиту на тестовому URL
