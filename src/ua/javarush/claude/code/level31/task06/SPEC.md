# SPEC — landing-audit-web

## Призначення

Інструмент перевіряє один лендінг за набором евристик і повертає короткий звіт
зі списком зауважень. Це навчальний demo-проєкт, а не комерційний продукт.

## Основний сценарій

1. Користувач вводить один URL лендінгу.
2. Інструмент бере HTML-сторінку з локальної фікстури (`test/fixtures/`).
3. Запускаються чотири евристики: наявність H1, заповнений `<title>`, непорожній
   meta description, наявність `alt` у зображень.
4. Повертається звіт зі списком знайдених зауважень.
5. Для валідної сторінки список зауважень порожній.

## Межі

- Реального мережевого fetch довільного URL з інтернету немає.
- Набір евристик фіксований (чотири перевірки), розширення поки що немає.
- Авторизації, бази даних і історії перевірок немає.
