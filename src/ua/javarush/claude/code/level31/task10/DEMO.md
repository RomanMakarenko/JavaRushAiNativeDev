# DEMO.md

## Сценарій демонстрації

1. Підняти середовище: `docker compose up -d`.
2. Імпортувати приклад виписки: `python -m app.cli import data/sample.csv`.
3. Побудувати звіт за квітень: `python -m app.cli report --month 2026-04`.
4. Показати категорії та підсумковий баланс у виводі звіту.

## Запасний варіант

Якщо live demo вередує, показати скріншоти прогону з `docs/screens/`.
