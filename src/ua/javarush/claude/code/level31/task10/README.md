# Personal CFO

Інструмент для solopreneur: імпортує банківську виписку в CSV, розподіляє
транзакції за категоріями та будує щомісячний фінансовий звіт.

## Швидкий старт

```bash
docker compose up -d
pytest -q            # 12 passed
python -m app.cli import data/sample.csv
python -m app.cli report --month 2026-04
```

## Основний потік

CSV → автоматична категоризація → місячний звіт.

## Відомі обмеження

- Усі приклади працюють у USD, багатовалютності поки що немає.
- У demo використовується один тестовий користувач.
- Імпорт CSV перевірено до 10MB.
- Реальні банківські API не підключені.
