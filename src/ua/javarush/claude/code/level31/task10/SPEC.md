# SPEC.md

## Problem

Solopreneur веде облік у таблицях вручну і не бачить місячний cashflow без
довгої ручної розмітки виписки.

## Scope

- Імпорт однієї CSV-виписки.
- Автоматична категоризація транзакцій за правилами.
- Місячний звіт: доходи, витрати, баланс за категоріями.

## Non-goals

- Немає інтеграції з банківськими API.
- Немає multi-currency.
- Немає багатокористувацької авторизації та signup.
- Немає повноцінної бухгалтерської системи.

## Verification

- `pytest -q` — unit і regression тести core flow.
- Smoke: імпорт `data/sample.csv` будує звіт за квітень.
