# Brainstorm — сирі ідеї

Звалище ідей до заморозки spec. Не все з цього увійде в поточний sprint.

- Завантаження CSV-виписки і парсинг рядків.
- Місячний звіт з розбивкою за категоріями.
- Авто-категоризація за ключовими словами в описі транзакції.
- PDF export готового звіту для відправлення бухгалтеру.
- Multi-currency: перерахунок витрат у базову валюту.
- OAuth-вхід через Google, щоб зберігати історію звітів.
- Графіки (pie chart) за категоріями витрат.
- Порівняння двох місяців між собою.
- Push-нагадування раз на місяць «завантаж виписку».
- Інтеграція з банківським API замість ручного завантаження CSV.
