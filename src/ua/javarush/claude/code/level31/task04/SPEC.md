# SPEC — personal-cfo-web (заморожено)

> Статус: **FROZEN** для поточного execution sprint. Будь-яке розширення обсягу — тільки через явне розморожування spec.

## Проблема
Фрилансери та приватні спеціалісти не розуміють, куди йдуть гроші: банківські виписки лежать у CSV, а звести їх у зрозумілий місячний звіт вручну довго й марудно.

## Цільовий користувач
Людина з нерегулярним доходом, яка раз на місяць хоче за пару хвилин побачити структуру витрат за категоріями.

## Core flow (демонстраційний шлях)
1. Користувач завантажує CSV з транзакціями.
2. Застосунок парсить рядки й розкладає суми за категоріями.
3. Будується місячний звіт: сумарний дохід, сумарна витрата, розбивка за категоріями.
4. Звіт показується на сторінці звіту.

## В обсязі (in scope)
- Завантаження CSV.
- Побудова місячного звіту (`buildMonthlyReport`).
- Перегляд звіту на сторінці.

## Поза обсягом (non-goals) для поточного sprint
- PDF export.
- OAuth / зовнішній login.
- Multi-currency analytics.
- Інтеграції з банківськими API.

## Success metric
Користувач від завантаження CSV до читабельного місячного звіту доходить менше ніж за хвилину.
