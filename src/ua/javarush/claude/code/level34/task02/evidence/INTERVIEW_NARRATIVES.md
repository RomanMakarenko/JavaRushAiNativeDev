# Interview narratives

Короткі історії для співбесіди, засновані на реальних діях у capstone.

## Як ловив баг із подвійним поверненням

Під час тестування refund flow виявив, що повторний запит створював друге
повернення. Написав failing regression-тест, локалізував причину в сервісному шарі,
зробив мінімальний fix і переконався, що тест став зеленим.

## Як використовував AI без втрати контролю

Claude Code застосовувався для investigation і чорновиків, але кожен diff
перевірявся вручну через self-review і проходив через CI quality gate.
Рішення про merge завжди залишалося за мною.
