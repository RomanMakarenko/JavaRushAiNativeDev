# Capstone summary — refund-сервіс

Коротке зведення по підсумковому проєкту для швидкого розуміння масштабу.

- Тип проєкту: backend-сервіс обробки повернень (refund flow) для навчального e-commerce.
- Стек: Java, Spring Boot, Gradle, PostgreSQL.
- Обсяг: один сервіс, близько 15 класів, REST API з 4 endpoint'ів.
- Тести: unit-тести бізнес-правил, integration-тести API, regression-тести на баги.
- CI: GitHub Actions з quality gate (build, tests, lint) перед merge у main.
- Роль у проєкті: єдиний автор, без команди і без production-розгортання.

Важливо: проєкт навчальний. Реального production traffic і людей у підпорядкуванні не було.
