# Role positioning workspace

Задача: зібрати стартовий профіль цільових ролей всередині Claude Code.

- `evidence/` — підтверджений досвід: proof of work, зведення capstone, історії для інтерв’ю.
- `career/target-roles.md` — цільовий документ, який потрібно заповнити.

Порядок роботи: відкрити Claude Code в цій директорії, виконати
`/rename role-positioning`, потім попросити заповнити `career/target-roles.md`
строго на основі evidence. Подача будується через традиційну інженерну роль,
AI — як differentiator, а не як окремий job title.
