Шановна командо Acme!

Мене зацікавила позиція Junior Backend Engineer у білінговій команді. У навчальному capstone-проєкті я самостійно розробив backend-сервіс обліку підписок на Java і Spring Boot та спроєктував REST API для створення, продовження й скасування підписок, а також розрахунку вартості. Деталі цього проєкту наведені в `evidence/capstone-summary.md`.

Я приділяю увагу тестуванню та інженерній дисципліні: реалізував unit-тести бізнес-правил, integration-тести REST-ендпоїнтів із Testcontainers і локальний CI-скрипт для перевірки збірки та тестів. У `evidence/PROOF_OF_WORK.md` також описані моя практика роботи з Git і code review, small diff та перевірними кроками.

Мій чесний gap — відсутність комерційного production-досвіду, експлуатації під реальним навантаженням і on-call; ці навички я ще маю здобути в команді. У workflow я використовую Claude Code для plan-first підходу, аналізу змін і підготовки малих diff, але рішення та фінальна перевірка залишаються за мною.

Буду радий обговорити, як мій досвід із Java, Spring Boot, REST API та тестуванням може бути корисним Acme на junior-рівні.
