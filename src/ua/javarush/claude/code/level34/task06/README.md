# Робочий простір кар’єри — супровідний лист без overclaim

Підготовка короткого супровідного листа під конкретну вакансію.

## Структура
- `career/applications/acme-backend/FIT_ANALYSIS.md` — аналіз відповідності вакансії.
- `career/applications/acme-backend/COVER_LETTER.md` — цільовий лист (заповнити).
- `evidence/PROOF_OF_WORK.md` — доказова база реальних артефактів.
- `evidence/capstone-summary.md` — короткий опис capstone-проєкту.

## Поточне завдання
Написати `COVER_LETTER.md`: чесний і короткий лист, що спирається на matched points
з `FIT_ANALYSIS.md` і реальні артефакти з `evidence`. Визнати принаймні один gap
без вигаданої компенсації. Без непідтверджених production-claims.
