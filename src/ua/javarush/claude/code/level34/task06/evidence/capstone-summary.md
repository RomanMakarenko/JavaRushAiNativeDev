# Capstone summary — сервіс обліку підписок

## Що це
Навчальний capstone-проєкт курсу: backend сервісу обліку підписок, виконаний solo.
Не production-сервіс; це демонстрація інженерної дисципліни на реалістичній задачі.

## Що зроблено
- Спроєктовано REST API: створення підписки, продовження, скасування, розрахунок вартості.
- Реалізовано бізнес-правила білінгу та покрито unit-тестами.
- Додано integration-тести на REST-ендпоїнти (Testcontainers, навчальний рівень).
- Налаштовано локальний CI-скрипт: збірка + тести перед кожним комітом.
- Зафіксовано SPEC.md і evidence log як контракт задачі.

## Межа чесності
- Сервіс не викладався в production і не працював під реальним навантаженням.
- Проєкт виконано в одиночку, без керування командою та релізами.
