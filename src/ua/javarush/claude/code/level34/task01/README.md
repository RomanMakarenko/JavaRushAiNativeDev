# Кар'єрний робочий простір

Робоча папка для підготовки виходу на ринок праці.

- `evidence/` — підтверджений досвід з попередніх модулів і capstone.
- `templates/` — шаблони стартових кар'єрних артефактів.
- `career/` — підсумкові career-документи (заповнюються на основі шаблонів).
- `submissions/` — артефакти для здачі завдань.

У першому завданні каркас збирається лише командами термінала: без редактора,
IDE та Claude Code.
