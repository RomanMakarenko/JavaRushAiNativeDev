# Підтвердження виконаної роботи — Олексій Карпов

Підсумок підтвердженого досвіду за результатами навчальних модулів і capstone-проєкту.
Кожен розділ спирається на реальні артефакти: коміти, PR, тести й документацію.

## Capstone: refund-сервіс

Реалізовано сервіс обробки повернень для навчального e-commerce проєкту.
Самостійно спроєктовано API, написано unit- та integration-тести,
налаштовано CI з quality gate перед merge у main.

## Backend і тестування

Покриття основної бізнес-логіки тестами доведено до робочого рівня,
додано regression-тести на знайдені баги, налаштовано звіт JaCoCo.

## AI-native робочий процес

Робота велася через Claude Code в режимі plan-first: investigation note,
затверджений план, невеликі перевірювані diff і self-review перед PR.

## Документація і handoff

Підготовлено CODEBASE_INVENTORY.md, HANDOFF_NOTE.md і run guide,
за якими інша людина може розгорнути проєкт і зрозуміти його структуру.
