# task-workspace — vacancy analysis

Робочий простір для структурного розбору вакансії.

## Структура

- `jobs/nimbus-backend.md` — вихідний текст вакансії.
- `evidence/PROOF_OF_WORK.md` — банк доказів досвіду кандидата.
- `career/applications/nimbus-backend/VACANCY_ANALYSIS.md` — артефакт для заповнення.

## Завдання

Відкрийте Claude Code в корені проєкту, виконайте `/rename vacancy-analysis` і
заповніть `VACANCY_ANALYSIS.md` структурованим аналізом вакансії. Розділяйте
факти з тексту вакансії та власні інтерпретації (hypothesis).
