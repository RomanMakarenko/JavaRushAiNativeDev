# Backend Engineer (Java) — Nimbus Payments

Nimbus Payments розвиває платіжну платформу: refund flow, підписки та білінг.
Ми шукаємо backend-інженера в команду, яка володіє своїм workstream від issue до PR.

## Що ви будете робити (Responsibilities)

- Розробляти та підтримувати backend-сервіси на Java і Spring Boot.
- Вести завдання в issue-to-PR циклі: розбір, реалізація, code review, merge.
- Покривати зміни тестами та підтримувати надійність платіжного flow.
- Брати участь у покращенні внутрішніх інструментів команди.

## Обов’язкові вимоги (must-have)

- Комерційний досвід на Java від 2 років.
- Spring Boot і побудова REST API.
- Реляційні бази даних (PostgreSQL) та впевнений SQL.
- Git і pull request workflow: гілки, code review, merge.
- Unit- і integration-тести на JUnit.

## Буде плюсом (nice-to-have)

- Docker і контейнеризація сервісів.
- CI/CD, наприклад GitHub Actions.
- Черги повідомлень (Kafka або RabbitMQ).
- Спостережуваність: логування та метрики.
- Навичка писати зрозумілу технічну документацію.

## Про команду

- Розподілена команда, віддалений формат.
- Ми цінуємо людей, які беруть ownership і швидко ростуть.
- Англійська на рівні читання технічної документації.
