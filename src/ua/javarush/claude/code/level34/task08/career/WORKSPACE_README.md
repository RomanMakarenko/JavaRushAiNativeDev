# Career workspace

## Layout

Ключові файли workspace:

- `career/JOB_TRACKER.md` — перелік заявок і поточні статуси.
- `career/target-roles.md` — цільові ролі та критерії пошуку.
- `career/applications/` — окрема папка для матеріалів кожної заявки.
- `career/WORKSPACE_README.md` — правила організації workspace.

## Per-application folder

Мінімальний набір файлів однієї заявки: `job.md` з описом вакансії та `application.md` з підготовленими матеріалами й нотатками щодо подання. Додаткові файли додаються лише за потреби.

## Human approval boundary

Claude пропонує вакансії, матеріали та наступні кроки. Людина перевіряє їх і затверджує відправлення заявки; без такого затвердження нічого не надсилається.

## Privacy

Workspace має бути private-by-default: його вміст призначений лише для локального використання та не публікується і не передається зовнішнім сервісам без явного дозволу людини.

## Weekly review

Раз на тиждень переглядайте `JOB_TRACKER.md`, оновлюйте статуси заявок, очищайте неактуальні нотатки та визначайте наступні кроки для активних заявок.
