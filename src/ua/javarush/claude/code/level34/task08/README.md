# Career workspace

Особистий workspace для відстеження заявок на вакансії. Тут зберігаються цільові ролі,
загальний tracker і папки конкретних заявок.

Структура:

- `career/JOB_TRACKER.md` — єдиний трекер усіх заявок.
- `career/target-roles.md` — цільові ролі та пріоритети пошуку.
- `career/applications/` — папки конкретних заявок (по одній на вакансію).

Важливо: workspace працює за принципом human-approved. Claude допомагає готувати чернетки
і оновлення, але рішення про відправлення завжди ухвалює людина.
