# Career workspace

Особистий workspace для відстеження заявок на вакансії. Тут зберігаються аналіз вакансій,
оцінка відповідності та загальний трекер усіх заявок.

Структура:

- `career/JOB_TRACKER.md` — єдиний трекер усіх заявок.
- `career/applications/` — папки конкретних заявок (по одній на вакансію).
- `inputs/` — вхідні матеріали (листи рекрутерів, нотатки).

Важливо: workspace працює за принципом human-approved. Claude допомагає готувати чернетки
й оновлення, але рішення про надсилання завжди ухвалює людина.
