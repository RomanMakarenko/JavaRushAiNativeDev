# task-workspace — fit analysis

Робочий простір для оцінки відповідності кандидата вакансії.

## Структура

- `career/applications/nimbus-backend/VACANCY_ANALYSIS.md` — готовий розбір вакансії.
- `evidence/PROOF_OF_WORK.md` — банк доказів досвіду.
- `evidence/capstone-summary.md` — короткий опис випускного проекту.
- `career/applications/nimbus-backend/FIT_ANALYSIS.md` — артефакт для заповнення.

## Задача

Заповніть `FIT_ANALYSIS.md`: зіставте must-have і nice-to-have вимоги
з реальним evidence, перелічіть gaps, зафіксуйте interview risks і прийміть
рішення за decision matrix (`apply` / `tailor-and-apply` / `build-evidence-first` / `skip`).
Рішення спирайте на must-have match, а не на загальні враження.
