# Робочий простір кар'єри — адаптоване резюме

Адаптація резюме під конкретну вакансію без вигадування досвіду.

## Структура
- `career/RESUME_BASE.md` — базове резюме (джерело істини).
- `career/applications/acme-backend/FIT_ANALYSIS.md` — аналіз відповідності вакансії.
- `career/applications/acme-backend/TAILORED_RESUME.md` — адаптоване резюме (починається як копія базового).
- `evidence/PROOF_OF_WORK.md` — доказова база реальних артефактів.

## Поточне завдання
У сесії Claude Code виконайте `/rename tailoring-session` і перепишіть
`TAILORED_RESUME.md`, спираючись лише на matched requirements і реальні evidence.
Жодних production / leadership claims без підтвердження.
