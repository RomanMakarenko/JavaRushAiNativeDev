# FIT_ANALYSIS — Acme, Junior Backend Engineer

## Вакансія
Acme шукає junior backend-розробника для команди білінгу. Стек: Java, Spring Boot,
PostgreSQL, REST API. Очікується дисципліна тестування та робота з code review.

## Matched requirements (збіги)
- Java і Spring Boot: підтверджується capstone-проєктом і pet-проєктами.
- REST API design: підтверджується API сервісу підписок у capstone.
- Дисципліна тестування: підтверджується unit- і integration-тестами в capstone.
- Робота з Git і code review: підтверджується історією комітів і review-практикою.
- AI-assisted workflow: підтверджується використанням Claude Code (plan-first, small diffs).

## Gaps (прогалини)
- Немає комерційного досвіду в команді на production.
- Немає досвіду PostgreSQL під реальним навантаженням (лише навчальні сценарії).
- Немає досвіду експлуатації та on-call.

## Висновок
Добрий fit на junior-рівні за технічним стеком і інженерною дисципліною;
основний gap — відсутність комерційного production-досвіду, який не можна вигадувати.
