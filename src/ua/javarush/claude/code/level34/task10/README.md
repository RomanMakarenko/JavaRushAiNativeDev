# Робочий простір take-home

Тут лежать матеріали виконаного тестового завдання (take-home):

- `takehome/brief.md` — умова завдання і політика щодо AI;
- `takehome/work-notes.md` — робочі нотатки про те, що робилося вручну, а де допомагав Claude Code;
- `takehome/AI_USAGE.md` — чесна нотатка про межі використання AI (заповнюється вами).

Мета `AI_USAGE.md` — прозоро показати рецензенту, де була ваша робота,
а де асистент, не приховуючи використання AI і не перекладаючи на нього відповідальність.
