# Take-home завдання: сервіс знижок

## Завдання

Реалізуйте невеликий REST-сервіс розрахунку знижки для кошика замовлення.
Стек на ваш вибір у межах JVM (переважно Spring Boot).

## Вимоги

- ендпоінт `POST /discount` приймає суму замовлення і код купона;
- розрахунок знижки покрито unit-тестами;
- до рішення додано короткий README з командою запуску.

## Політика щодо AI

Використання AI-асистентів (включно з Claude Code) дозволено
за умови чесного розкриття: додайте файл `AI_USAGE.md`,
де описано, що ви робили самі, а де допомагав асистент.
Фінальне рішення і його коректність залишаються вашою відповідальністю.

## Строк

3 робочі дні.
