# assessment-policy-check

Невелика утиліта для перевірки політики використання AI у тестових завданнях
(coding assessments, take-home tasks).

## Запуск перевірки

```bash
python tools/validate_assessment_policy.py career/assessment-policy.yml
```

Валідатор виводить `OK`, якщо конфіг описує коректний набір статусів
і задає безпечну поведінку за замовчуванням.

## Стани політики

- `forbidden` — використання AI в завданні заборонено;
- `allowed-with-disclosure` — AI дозволено за чесного розкриття;
- `ask-first` — потрібно уточнити в компанії перед початком.

Якщо статус невідомий, політика має за замовчуванням вести до `ask-first`,
а не вважати дію дозволеною.
