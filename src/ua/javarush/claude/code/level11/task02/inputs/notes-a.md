# Нотатки з організації AI-роботи (частина A)

Сьогодні обговорювали, як ми взагалі запускаємо Claude Code на модулі auth.

Для дослідження auth-модуля потрібен read-only subagent: нехай прочитає файли, збере факти й поверне коротке summary в поточну сесію.

Якщо завдання суто дослідницьке, окрема worktree-backed session тут зайва.

Довгий скан усього репозиторію зручніше віддати в background agent: задали роботу, пішли пити чай, потім повернулися за результатом.

Не плутати subagent з окремою розмовою: subagent вбудований у поточний workflow.
