# Нотатки з організації AI-роботи (частина B)

Коли стара сесія обросла гіпотезами й невдалими ходами, чесніше відкрити separate session і перескласти розуміння проблеми з нуля.

Ризиковану альтернативну реалізацію bugfix краще пробувати у worktree-backed session, щоб не чіпати основне working tree.

Ідея зібрати agent team із планувальника, кодера та тестувальника звучить бадьоро, але на базовому рівні частіше потрібен один нормально спроєктований subagent.

Ще раз для протоколу: separate session не зобов’язана автоматично повертати результат у поточну розмову, на відміну від subagent.
