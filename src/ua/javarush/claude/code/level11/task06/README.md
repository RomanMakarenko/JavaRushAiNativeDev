# commerce-os

Невеликий сервіс каталогу та замовлень на Spring Boot 4.0. Команда починає
заводити кастомних subagent-ів і хоче першого спільного reviewer-агента, який
перевірятиме diff перед PR.

## Структура

- `src/` — вихідний код сервісу (у цій задачі не чіпаємо)
- `.claude/agents/` — project-scope агенти команди, їдуть разом із кодом у Git
- `submissions/` — робочі артефакти за задачами

## Що потрібно

Перший reviewer має бути read-only: читає код і diff, нічого не править.
Для старту беремо мінімальний каркас без advanced-конфігурації.
