Використовуй, коли потрібен чорновик release notes для внутрішнього релізу Commerce OS.

Вхід: список merged PR (заголовки рядками), наприклад із `inputs/merged-prs.txt`.

Поверни три розділи:
1. user-facing — що помітить користувач;
2. fixes — виправлені баги;
3. internal — внутрішні та технічні зміни.

Кожен пункт має посилатися на конкретний PR із вхідного списку.
Не додавай змін, яких немає у вході.
