# Нотатка рецензента

Я переглядаю кожен PR у checkout-service вручну. Для мене важливо:

- що зміна бізнес-логіки покрита тестами;
- що немає витоку secret'ів і хардкоду ключів;
- що міграції БД зворотні.

Approval ставлю лише після ручного перегляду diff. Зелений CI — необхідна,
але не достатня умова: human review залишається окремим обов’язковим шаром.
