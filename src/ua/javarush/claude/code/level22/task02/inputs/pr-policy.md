# Політика PR → main (Commerce OS)

Merge у гілку `main` дозволено лише після проходження quality gate.

Правила:

- Усі deterministic checks із CI мають бути зеленими. Падіння будь-якого з них
  блокує merge.
- Потрібен щонайменше один approval від reviewer'а з команди checkout.
  Approval людини є обов’язковим і не може бути замінений автоматикою.
- AI-assisted review запускається на кожен PR, але його результат має
  рекомендаційний характер і не блокує merge самостійно.
- Метрика `coverage-delta` збирається для спостереження і не є
  обов’язковою умовою проходження.
