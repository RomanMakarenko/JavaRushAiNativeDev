# API: повернення

## Створення повернення

`POST /api/orders/{id}/refund`

Створює запит на повернення для замовлення з ідентифікатором `{id}`.

### Параметри шляху

| Параметр | Тип    | Опис                 |
|----------|--------|--------------------------|
| `id`     | string | Ідентифікатор замовлення     |

### Приклад відповіді

```json
{
  "orderId": "ORD-1001",
  "status": "REFUND_REQUESTED"
}
```

Це узгоджений контракт. Для backend-коду він є source of truth.
