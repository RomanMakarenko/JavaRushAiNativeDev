# Формат і історія проєкту

## Обраний формат

**Legacy modernization mini-project** — мініпроєкт модернізації legacy-коду.

## Чому цей формат

Ідея передбачає невеликий, але реалістичний і контрольований зріз роботи з
legacy-сервісом CashFlow Dashboard: оновлення залежностей, упорядкування одного
модуля розрахунку MRR та покриття цього модуля тестами. Такий формат відповідає
обмеженому обсягу capstone і дає змогу перевірити результат на конкретній
проблемі — розбіжності розрахунку MRR із білінгом приблизно на 8%.

Основний міграційний крок — перехід до Spring Boot 3.x і Java 21. Перехід до
Boot 4 та Java 25 залишається необов'язковим розширенням, а не частиною
обов'язкової роботи.

## Межа проєкту

**Capstone — окремий проєкт, а CashFlow Dashboard — лише навчальний
legacy-контекст: робота виконується в окремому репозиторії на копії потрібного
модуля й не змінює бойовий сервіс.**
