# Capstone — вибір формату з валідованим конфігом

Задача: вибрати один формат із brief, записати його в конфіг і пояснити
рішення.

## Кроки

1. Прочитати `CAPSTONE_BRIEF.md` та `inputs/idea.md` через Claude Code.
2. Заповнити поле `format` у `config/capstone-format.json` (рівно одне
   значення із закритого списку).
3. Описати вибір у `docs/FORMAT_AND_STORY.md`.
4. Запустити валідацію:

```bash
python scripts/validate_format.py config/capstone-format.json
```

Команда має завершитися успішно (код 0).

## Правила

- У конфігу заповнюється лише поле `format`.
- Значення — один із шести допустимих форматів.
- Нові файли поза зазначеною областю не створюються.
