# Ідея проєкту

Усередині команди є legacy-сервіс CashFlow Dashboard, який рахує MRR.
Зараз він написаний на старому Spring Boot і старій версії Java, тести місцями
не проходять, а розрахунок MRR розходиться з білінгом приблизно на 8%.

Мій план для capstone — взяти невеликий, але реалістичний шматок цього
legacy-сервісу й акуратно його модернізувати: підтягнути залежності,
навести лад в одному модулі розрахунку MRR і закрити його тестами. Основний
міграційний крок — перехід до Boot 3.x + Java 21. Повний стрибок до Boot 4 +
Java 25 поки не планую, залишу його як можливе розширення.

Усе робитиму в окремому репозиторії, на копії потрібного модуля, не чіпаючи
бойовий CashFlow Dashboard.
