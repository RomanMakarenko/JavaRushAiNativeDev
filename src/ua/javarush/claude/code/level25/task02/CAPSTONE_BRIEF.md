# Короткий опис capstone

Фінальний проєкт курсу «Claude Code: AI-native Software Engineer» — це
самостійний репозиторій студента. Він не є продовженням навчальних
проєктів Commerce OS або CashFlow Dashboard: ці сервіси використовуються лише
як приклади та legacy-контекст.

## Дозволені формати

Потрібно обрати рівно один формат із закритого списку:

1. Feature in existing codebase
2. AI-native MVP
3. Legacy modernization mini-project
4. Migration slice
5. DevOps automation
6. Team workflow design

Будь-які варіанти поза цим списком (наприклад `Custom project` або `Anything else`)
не допускаються.

## Міграційний контекст

Основний міграційний крок обмежений переходом до Boot 3.x + Java 21. Перехід до
Boot 4 + Java 25 вважається optional extension і не входить до обов'язкової частини
роботи.
