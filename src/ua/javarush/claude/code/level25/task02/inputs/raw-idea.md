# Сира ідея проєкту

Хочу зібрати невеликий сервіс, який допомагає фінансовій команді ловити
розбіжності в розрахунку MRR. Зараз у legacy-сервісі CashFlow Dashboard цифра
MRR розходиться з білінгом приблизно на 8%, і ніхто не розуміє чому.

Ідея: окремий маленький інструмент, який бере вивантаження підписок,
перераховує MRR за зрозумілими правилами і показує, де саме розходиться з
поточним розрахунком. Хочеться отримати робочий прототип з нуля, а не доопрацьовувати
сам CashFlow Dashboard.

Технічно хочеться почати з чистого Spring Boot 3.x на Java 21. Жодної
великої кодової бази під рукою немає — усе роблю з порожнього репозиторію.
