# Capstone — вибір формату через Claude Code

Завдання: у сесії Claude Code прочитати `CAPSTONE_BRIEF.md` і
`inputs/raw-idea.md`, після чого підготувати коротке рішення про вибір формату
в `submissions/FORMAT_DECISION.md`.

## Правила

- Обрати рівно один формат із закритого списку brief.
- Надати щонайменше 2 причини, спираючись на brief і raw idea.
- Додати фразу, що capstone — окремий репозиторій студента.
- Не додавати implementation plan, backlog і код.
- Файли в `inputs` не змінювати.
