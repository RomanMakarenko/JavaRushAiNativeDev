# Level Fit

## Рівень

**Middle.** Профіль відповідає реалізації одного повного flow у Java/Spring Boot із базовою обробкою помилок, happy path і negative scenario. Це дає змогу показати планування, малі diff, evidence log і локальну verification, але не вимагає ще не сформованих production-інфраструктури, архітектурних меж та автоматизованого harness рівня Senior.

## Формат

**New small product** — невеликий сервіс керування підписками для SaaS-команди.

## Core flow першої версії

**Оператор оформлює підписку в локальному demo-режимі:** надсилає дані організації, клієнта й плану; сервіс валідовує запит, зберігає підписку зі статусом `ACTIVE` та повертає результат. Для flow передбачити основні помилки, зокрема невалідний план або повторне оформлення підписки.

## Що прибирається з першої версії

- скасування підписки як окремий flow;
- реальна оплата та інтеграція зі Stripe;
- multi-tenant режим;
- AWS-деплой і production CI/CD;
- email- та push-кампанії;
- аналітичний дашборд і графіки виручки;
- синхронізація макетів із Figma;
- multi-agent orchestration;
- будь-яка production-інфраструктура, не потрібна для локального demo-ready запуску.
