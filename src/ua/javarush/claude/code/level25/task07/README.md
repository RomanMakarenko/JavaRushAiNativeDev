# subscription-tracker

Capstone-проєкт: невеликий backend-сервіс обліку підписок користувачів.
Підраховує активні підписки, помісячну виручку (MRR) і найближчі списання.

## Технології

- Kotlin 1.9
- Gradle (Kotlin DSL)
- JUnit 5

## Команди

- Збірка: `./gradlew build`
- Тести: `./gradlew test`
- Локальний запуск: `./gradlew run`

## Статус

Початковий baseline проєкту. Основна робота ще не починалася.
