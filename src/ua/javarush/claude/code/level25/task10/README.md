# MealPlan — capstone-проєкт

Невеликий web-застосунок для планування харчування на тиждень.
Один core flow: користувач додає страву до плану дня і бачить оновлений список.

## Локальні перевірки

Дорожня карта спирається на відтворювану локальну перевірку core flow:

```
npm run smoke
```

Ця команда запускає `scripts/smoke-check.mjs` і перевіряє, що core flow працює.

```
npm test
```

Запускає тести проєкту, зокрема перевірку набору package scripts.
