# Хто користувач

Основний користувач — підписник сервісу, у якого з часом накопичується
історія підписок: щось він продовжує, щось скасовує.

Біль користувача: на екрані "Мої підписки" в купі перемішані активні й
скасовані записи, і незрозуміло, за що він реально платить просто зараз.

Очікування: бачити короткий і чесний список того, що діє в цей момент.

Другорядні читачі документа: ментор і reviewer, які перевірятимуть,
чи відповідає реалізація заявленому контракту.
