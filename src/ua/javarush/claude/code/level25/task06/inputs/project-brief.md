# Brief: сервіс списку підписок

Потрібен невеликий backend-сервіс, який показує користувачеві його підписки.
Це частина навчальної capstone-задачі, розрахованої на кілька тижнів роботи.

Головна цінність: користувач відкриває екран "Мої підписки" і бачить тільки
ті підписки, які зараз діють (active). Скасовані (cancelled) підписки
не повинні заважати і не повинні потрапляти до цього списку.

Обмеження проєкту:
- стек — Java + Gradle;
- HTTP-ендпоінт `GET /subscriptions/active` повертає JSON зі списком активних підписок;
- сховище на старті можна тримати in-memory, без справжньої БД.

Строки і команда: один автор, рев'ю в ментора раз на тиждень.
