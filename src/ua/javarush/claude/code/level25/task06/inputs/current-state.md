# Поточний стан проєкту

Зараз у репозиторії є лише заготовка:

- збирається через `./gradlew build`;
- є клас `SubscriptionService` з методом, який має повертати активні
  підписки, але поки повертає взагалі всі записи, включно з cancelled;
- є один чорновий тест, який цей баг не ловить;
- ендпоінт `GET /subscriptions/active` уже оголошено в контролері.

Відомі проблеми:
- логіка фільтрації за статусом не реалізована;
- немає regression-тесту на правило "тільки активні".

Що НЕ входить до поточного проєкту: оплата, PDF-експорт списку, сповіщення.
