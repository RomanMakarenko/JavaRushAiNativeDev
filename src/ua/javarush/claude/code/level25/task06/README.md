# Subscriptions Service

Навчальний capstone-проєкт: backend-сервіс списку підписок.

## Збірка та перевірка

- `./gradlew build` — збірка проєкту
- `./gradlew test` — запуск тестів

## Ендпоінти

- `GET /subscriptions/active` — список активних підписок користувача

## Документація

- `inputs/` — вихідні матеріали (brief, нотатки про користувача та стан проєкту)
- `docs/SPEC.md` — інженерний контракт довгої задачі (потрібно заповнити)
