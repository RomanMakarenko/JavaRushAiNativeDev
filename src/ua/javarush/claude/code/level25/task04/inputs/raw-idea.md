# Сира ідея проєкту

Хочу зробити сервіс керування підписками для маленької SaaS-команди.

Що хотілося б всередині:

- Оформлення та скасування підписки оператором.
- Реальна оплата через платіжного провайдера (Stripe).
- Multi-tenant режим: кілька організацій в одній інсталяції.
- Автодеплой в AWS з налаштованим CI/CD.
- Email- і push-кампанії під час зміни статусу підписки.
- Дашборд аналітики з графіками по виручці.
- Інтеграція з Figma для синхронізації макетів білінгу.
- Multi-agent orchestration для автоматичної обробки тікетів.

По суті все це одразу в першу версію.
