# Capstone brief

Capstone — це довга інженерна задача, яку студент веде за AI-native workflow:
план, невеликі diff, evidence log і перевірюваний результат.

## Допустимі формати проєкту

Обирається рівно один формат:

- `New small product` — невеликий власний продукт з одним core flow.
- `Feature on top of starter` — фіча поверх готового starter-репозиторію.
- `Bugfix-and-harden` — виправлення й зміцнення наявного проєкту.
- `Refactor slice` — безпечний refactor виділеного слайсу коду.
- `Migration slice` — вузька міграція (версія залежності, пакет, runtime).
- `Internal tool` — невеликий внутрішній інструмент для команди.

## Загальні правила

- Рівень і формат фіксуються до написання `SPEC.md`.
- Production deployment не входить до обов'язкового scope.
- Demo-ready результат достатній для захисту.
- Scope звужується до одного core flow; зайві фічі відкладаються.
