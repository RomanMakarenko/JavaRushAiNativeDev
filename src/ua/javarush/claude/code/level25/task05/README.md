# Subscriptions Service

Невеликий сервіс списку підписок користувача. Це базовий проєкт для capstone-завдання.

## Структура

- `docs/` — проєктна документація (поки порожня)

## Подальші кроки

Перед початком реалізації довгого завдання потрібно зафіксувати інженерний контракт
у файлі `docs/SPEC.md`. На першому кроці створюється лише каркас (skeleton) з
обов'язковими заголовками розділів.
