# SPEC — MealPlan

Інженерний контракт першої версії capstone-проєкту.

## Problem

Студенту/користувачу складно тримати план харчування на тиждень в одному місці:
нотатки розкидані, немає єдиного списку страв за днями.

## Core scenario

1. Користувач обирає день тижня.
2. Додає в цей день страву.
3. Бачить оновлений список страв обраного дня.

## Scope

- В scope: один core flow «додати страву до плану дня».
- Non-goals: рецепти, калорії, синхронізація між пристроями, акаунти.

## Verification

- Локальна smoke-перевірка core flow.
- Evidence log фіксує кожен значущий крок.

## Success criteria

- Core flow відтворювано проходить локальну перевірку.
- Документація та traceability в актуальному стані.
