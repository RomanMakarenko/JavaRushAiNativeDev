# MealPlan — capstone-проєкт

Невеликий web-застосунок для планування харчування на тиждень.
Один core flow: користувач додає страву до плану дня і бачить оновлений список.

Це AI-native capstone: робота ведеться короткими slice-ами, кожен значущий крок
фіксується в evidence log, а загальна траєкторія описана в roadmap.

## Структура

```
README.md            — цей файл
docs/SPEC.md         — інженерний контракт проєкту
docs/ROADMAP.md      — дорожня карта і preview критеріїв оцінювання
src/                 — вихідний код застосунку
```

## Локальні перевірки

Команди для відтворюваної перевірки з’являються в міру готовності roadmap.
