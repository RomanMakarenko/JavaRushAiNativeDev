# REF-482 — Заявки на ручну перевірку губляться внизу списку повернень

Статус: open
Пріоритет: high
Мітки: refunds, sorting, support-tools

## Що відбувається

Агенти підтримки відкривають список повернень у support-toolbar і працюють
з ним зверху вниз. Заявки з прапорцем `manualReview=true` потребують рішення
людини, але зараз вони тонуть серед звичайних заявок і обробляються із
затримкою.

## Очікувана поведінка

Заявки з `manualReview=true` мають показуватися вище за звичайні. Усередині
кожної групи порядок — від новіших до старіших (за часом створення).

## Поточна поведінка

Список сортується лише за часом створення, без урахування прапорця
ручної перевірки.

## Де дивитися

Сигнал прийшов із issue tracker. Ендпойнт списку повернень і логіка
сортування живуть у модулі `refunds`.
