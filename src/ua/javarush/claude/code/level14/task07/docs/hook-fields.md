# Поля конфігурації hook

> Точні назви подій і прапорців можуть відрізнятися у вашій версії Claude Code.
> Орієнтуйтеся на `/hooks` і актуальну документацію. Важлива логіка, а не
> конкретний JSON-синтаксис.

| Поле               | Призначення                                                        |
|--------------------|--------------------------------------------------------------------|
| `name`             | Унікальна назва hook                                               |
| `stage`            | Поточний етап розгортання (`log-only` ... `policy-managed`)        |
| `category`         | `blocking` або `non-blocking`                                      |
| `event`            | Коли спрацьовує: `afterFileEdit`, `beforeToolUse` тощо             |
| `matcher.tool`     | Обмеження за інструментом, наприклад `Write`                       |
| `matcher.paths`    | Список glob-шляхів, на які реагує hook                             |
| `handler.command`  | Команда обробника; `{{file}}` підставляє шлях до файла             |
| `handler.blocking` | `true` — дію можна скасувати ненульовим exit code                  |

## Характер втручання

- **before-tool event** (`beforeToolUse`) дозволяє зупинити дію ДО її
  виконання. Якщо handler повертає ненульовий exit code і `blocking: true`,
  операція блокується.
- **after-edit event** (`afterFileEdit`) спрацьовує вже ПІСЛЯ зміни файла —
  підходить для форматування і звітування, але не для блокування запису.
