# FastAPI — root_path (витяг із docs)

Коли застосунок FastAPI працює за проксі, шлях префікса (наприклад
`/api`) обрізається проксі й не доходить до застосунку. Щоб FastAPI
будував коректні URL і правильну схему OpenAPI, потрібно передати йому
параметр `root_path`.

`root_path` задається під час створення застосунку:

```python
app = FastAPI(root_path="/api")
```

Важливе:

- `root_path` впливає на шляхи в згенерованій OpenAPI-схемі та на
  адресу інтерактивної документації `/docs`.
- `root_path` не змінює фактичні маршрути, оголошені в коді,
  він лише повідомляє застосунку про зовнішній префікс.
- Значення має збігатися з префіксом, який відрізає проксі.
