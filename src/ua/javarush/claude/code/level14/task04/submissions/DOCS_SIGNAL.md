# DOCS_SIGNAL — fastapi-root-path

- **Факт із docs:** `root_path` задається під час створення застосунку (`FastAPI(root_path="/api")`) — він впливає на шляхи в згенерованій OpenAPI-схемі та на адресу `/docs`, але не змінює фактичні маршрути, оголошені в коді; значення має збігатися з префіксом, який відрізає проксі.

- **Файл проєкту, який може зачепити:** `app/main.py` — саме там створюється екземпляр `FastAPI`, і якщо `root_path` не збігається з проксі-префіксом, OpenAPI-схема та документація будуть зламані.

- **Локальна команда-перевірка:** запуск тесту `pytest tests/test_root_path.py`, який перевіряє, що `app.root_path == "/api"`.

> **Docs — це довідкове джерело.** Нотатка з docs описує, як правильно налаштовувати застосунок за проксі, але не є підставою для автоматичної зміни коду. Рішення про зміни ухвалює розробник на основі контексту проєкту.
