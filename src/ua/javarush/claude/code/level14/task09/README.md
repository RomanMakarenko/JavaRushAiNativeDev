# Workflow Kit — відновлення hooks

Командний набір automation-хуків для проєкту AI Commerce Growth OS.

## Шлях швидкого вимкнення

Якщо hook починає заважати роботі, перше завдання — швидко повернути керованість,
а не виправляти архітектурно. У цьому репозиторії quick disable влаштовано так:

1. Беремо проблемний hook із `.claude/hooks/`.
2. Переміщаємо його файл до `.claude/hooks-disabled/`.
3. Після цього hook list (наприклад, `/hooks`) більше не вважає його активним.

Це саме recovery, а не видалення: hook зберігається в репозиторії і може бути
повернутий назад після фіксу. Папка `.claude/hooks-disabled/` існує завжди
(у ній лежить `.gitkeep`), навіть коли вимкнених хуків немає.

## Поточний стан

Активний шумний `format-on-edit`: matcher розширено до `frontend/src/**/*` і
чіпляє generated-файли. До центрального фіксу hook потрібно тимчасово вимкнути.
