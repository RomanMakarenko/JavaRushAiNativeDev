# Інтерв’ю 2 — Олег, провідний оператор підтримки

- Роль: провідний оператор підтримки, допомагає першій лінії зі складними випадками.
- Підтверджує дорогі повернення вручну, бо автоматиці поки не довіряють.
- "Якщо повернення більше ніж сотня, я обов’язково дивлюся тікет власними очима, перш ніж погодити."
- Скаржиться, що немає єдиного місця, де видно всю історію по клієнту, доводиться відкривати
  три різні вкладки.
- Вважає, що головний показник хорошої роботи — це скільки тікетів закрито без повторного
  звернення клієнта.
- Оцінює, що повторні звернення зараз становлять близько 18% від усіх тікетів.
