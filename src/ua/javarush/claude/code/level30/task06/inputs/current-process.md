# Поточний процес обробки тікетів

1. Тікет потрапляє в загальну чергу без пріоритизації.
2. Оператор першої лінії відкриває тікет і визначає тип запиту вручну.
3. Для повернень оператор шукає схожий попередній тікет і копіює шаблон відповіді.
4. Якщо сума повернення велика, потрібне ручне погодження у провідного оператора.
5. Відповідь надсилається клієнту, тікет закривається.

Вузькі місця:
- Ручний пошук шаблону займає час на кожному тікеті.
- Немає чіткого порогу, після якого повернення йде на ручне підтвердження.
- Історія по клієнту розкидана по кількох системах.
