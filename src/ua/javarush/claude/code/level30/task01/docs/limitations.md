# Обмеження поточної збірки

- Працює лише на локальному наборі `data/sample-tickets.json`, без підключення до реальної БД замовлень.
- Немає авторизації операторів і розмежування прав.
- Чорновик відповіді завжди потребує ручної перевірки людиною перед надсиланням.
- Немає обробки помилок і повторних спроб у разі збою — це demo, не production.
