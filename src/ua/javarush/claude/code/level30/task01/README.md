# Order Support Tool

Невеликий інструмент підтримки замовлень. Поточна збірка призначена для демонстрації
одного робочого потоку: оператор бере заявку, інструмент готує чорновик відповіді,
оператор перевіряє та надсилає.

## Що всередині

- `data/sample-tickets.json` — набір тестових тикетів, на яких працює збірка.
- `scripts/run-demo.sh` — запуск демонстраційного сценарію на sample data.
- `docs/limitations.md` — чесний список обмежень поточної версії.

## Як запустити демо

```
bash scripts/run-demo.sh
```

Реальна інтеграція з поштою, білінгом і базою замовлень поки не підключена —
усе працює на локальному наборі sample tickets.
