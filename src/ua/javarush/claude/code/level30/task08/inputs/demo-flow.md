# Поточний demo-flow

Зв'язний маршрут, який уже проходить від початку до кінця:

1. Клієнт створює тикет — тикет з'являється в inbox оператора.
2. Тема тикета визначається автоматично (billing / technical / account).
3. AI генерує чернетку відповіді в панелі review.
4. Оператор перевіряє чернетку й сам натискає Send.
5. Дії по тикету записуються в audit trail.

Голос, аналітика, CRM sync і мультимовність у demo сирі та нестабільні.
