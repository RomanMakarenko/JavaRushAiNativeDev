# Backlog support-demo

Сирий список ідей для AI-помічника служби підтримки. Пріоритети не розставлені.

- Прийом вхідного тикета в inbox і показ оператору.
- Автокласифікація теми тикета (billing, technical, account).
- Генерація чернетки відповіді, яку людина перевіряє перед надсиланням.
- Журнал дій по тикету (audit trail).
- Голосова підтримка: прийом дзвінків і розшифрування.
- Дашборд аналітики по черзі та операторам.
- Двостороння синхронізація із зовнішньою CRM.
- Переклад відповідей на 12 мов.
- Автоескалація при порушенні SLA.
- Автовідправлення відповіді клієнту без участі людини.
