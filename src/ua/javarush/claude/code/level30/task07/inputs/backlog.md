# Backlog support-demo

Сирий список ідей для AI-помічника служби підтримки. Пріоритети не визначені.

- Прийом вхідного тікета в inbox і показ оператору.
- Автокласифікація теми тікета (billing, technical, account).
- Генерація чернетки відповіді, яку людина перевіряє перед надсиланням.
- Журнал дій за тікетом (audit trail).
- Голосова підтримка: прийом дзвінків і розшифровка.
- Дашборд аналітики по черзі та операторам.
- Двостороння синхронізація із зовнішньою CRM.
- Переклад відповідей на 12 мов.
- Автоескалація у разі порушення SLA.
- Автовідправлення відповіді клієнту без участі людини.
