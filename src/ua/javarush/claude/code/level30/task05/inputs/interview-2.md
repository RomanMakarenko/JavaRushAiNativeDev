# Інтерв'ю 2 — Олег, старший оператор підтримки

- Роль: старший оператор підтримки, допомагає першій лінії зі складними випадками.
- Підтверджує дорогі повернення вручну, бо автоматизованій системі поки не довіряють.
- "Якщо повернення більше ніж на сотню, я обов'язково дивлюся на тикет власноруч, перш ніж погодити."
- Скаржиться, що немає єдиного місця, де видно всю історію по клієнту, доводиться відкривати
  три різні вкладки.
- Вважає, що головний показник хорошої роботи — це скільки тикетів закрито без повторного
  звернення клієнта.
- Оцінює, що повторні звернення зараз становлять близько 18% від усіх тикетів.
