# Сирова ідея

Інструмент ШІ для підтримки e-commerce.

Формулювання поки що надто загальне: незрозуміло, для кого саме продукт, яку
конкретну проблему він знімає і який результат можна показати на демо. Потрібно
звузити це до одного зрозумілого фокуса проєкту.

Контекст із нотаток команди (для опори):
- користувач — агент першої лінії підтримки в невеликому магазині;
- проблема — ручне сортування вхідних тікетів за темами забирає 40–60 секунд на тікет;
- очікуваний результат — автокласифікація зменшує час сортування до менш ніж 5 секунд.
