# Нотатка про залежності

Класифікація тем зараз зав’язана на зовнішній платний сервіс TopClass Classify API
(потребує API token). Для демо це крихка опора: сервіс може бути недоступним у
будь-яку мить.

Є локальна альтернатива: local-sample-classifier — stub-провайдер, який
працює без мережі й підходить для відтворюваної демонстрації.
