# Ціннісна пропозиція

Агент першої лінії підтримки в невеликому інтернет-магазині використовує інструмент ШІ для автоматичної класифікації вхідних тікетів за темами, щоб усунути ручне сортування, яке зараз займає 40–60 секунд на кожен тікет, і скоротити цей час до менш ніж 5 секунд на тікет.

## Dependency risk

Класифікація залежить від зовнішнього платного TopClass Classify API та API token, тому його недоступність може зірвати демо; для відтворюваної демонстрації слід передбачити локальний `local-sample-classifier`.
