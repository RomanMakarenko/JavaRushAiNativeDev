# Чесна форма артефакту

## Artifact type

**demo** — локальна демонстраційна збірка на sample data.

## One core flow

Оператор обирає sample ticket, а інструмент готує для нього чернетку відповіді.

## Honest limitations

- Працює лише на локальному наборі з 5 sample tickets.
- Не підключений до реальних замовлень або реальної бази замовлень.
- Відсутня інтеграція з поштою та білінгом.
- Немає авторизації та розмежування прав операторів.
- Кожна чернетка потребує ручної перевірки людиною.
- Немає обробки помилок, повторних спроб (retry) і моніторингу.
- Запускається лише локально через `scripts/run-demo.sh`; серверного розгортання немає.
