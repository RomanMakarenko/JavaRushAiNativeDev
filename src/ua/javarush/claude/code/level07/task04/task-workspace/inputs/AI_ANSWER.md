# Відповідь AI: як влаштовано login flow

## Claim

Застосунок використовує stateless-автентифікацію на JWT. Після логіну сервер
повертає JWT-токен, а фронтенд зберігає його в `localStorage` і додає
до кожного запиту в заголовку `Authorization: Bearer <token>`. Жодної
серверної сесії немає.

## Evidence

- Логін повертає токен у тілі відповіді.
- Токен перевіряється на кожному запиті фільтром у `SecurityConfig`.

## Confidence

Висока. Це типовий патерн для Spring Boot REST API, тому тут майже
напевно застосовується саме він.
