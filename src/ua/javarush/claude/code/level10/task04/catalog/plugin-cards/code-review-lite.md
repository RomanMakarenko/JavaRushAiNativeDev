# code-review-lite

- Категорія: `code-review`
- Зірки: 410

## Що робить

Легкий помічник для рев’ю PR: підсвічує ризиковані ділянки diff'а, готує
короткий summary змін і пропонує чекліст для рев’юера.

## Навіщо команді

Закриває основну проблему: прискорює розбір diff'а і формує summary PR, якого
зараз не вистачає.
