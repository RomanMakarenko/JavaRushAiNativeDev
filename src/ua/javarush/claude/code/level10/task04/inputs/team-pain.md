# Поточний біль backend-команди

Ми — backend-команда сервісу Commerce OS (Java 25 + Spring Boot 4). Основний час
втрачаємо не на написання коду, а на рев’ю pull request'ів.

## Що болить прямо зараз

- Рев’ю diff'а займає надто багато часу: зміни великі, контекст доводиться
  збирати вручну з кількох файлів.
- В описах PR часто немає чіткого summary — рев’юер сам розбирається, що і навіщо
  змінилося.
- Нові учасники команди довго входять у проєкт: їм ніде швидко взяти контекст
  щодо попередніх рішень.

## Що НЕ болить

- Нам не потрібна автоматизація браузера — у backend-сервісу немає UI-тестів у нашому
  контурі.
- Нам не потрібні інструменти для frontend-дизайну та оформлення інтерфейсу.

## Висновок

Зараз пріоритет — прискорити й упорядкувати PR review. Усе інше — потім.
