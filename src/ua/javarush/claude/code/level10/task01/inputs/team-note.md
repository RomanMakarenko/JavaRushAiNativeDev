# Нотатка команди

`issue-analysis` використовують майже всі: бекенд-розробники з Commerce OS, команда Cashflow Dashboard і команда загального Workflow Kit. Щоразу, коли заводять нову задачу, хтось та й проганяє issue через цей workflow.

`project-setup` — це історія лише про Commerce OS. Ним налаштовують локальне середовище саме цього проєкту, в інших репозиторіях він марний: там інший стек і інші seed-дані.
