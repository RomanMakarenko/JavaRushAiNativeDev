# Налаштування проєкту

Використовуй цей workflow для первинного налаштування локального середовища проєкту Commerce OS.

## Кроки

1. Скопіюй `.env.example` у `.env` і заповни локальні значення.
2. Накатай seed-дані командою проєкту.
3. Запусти smoke-перевірку, що сервіс стартує.
