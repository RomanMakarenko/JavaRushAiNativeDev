# Нотатка про встановлення плагінів

Тут фіксується, у якому scope встановлено кожен плагін і чому.

## team-review-kit

Плагін встановлено в scope `local`. Для експерименту одного розробника
вибрано `local`, тому що радіус впливу менший — плагін діє лише в межах
локальної копії та не зачіпає інших учасників проєкту.
