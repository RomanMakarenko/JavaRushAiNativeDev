# Аналіз issue

Використовуй цей workflow, коли потрібно перетворити сирий issue на інженерну специфікацію.

## Кроки

1. Прочитай сирий текст issue цілком.
2. Сформулюй один перевірний Goal.
3. Опиши Scope: що входить до зміни.
4. Переліч Acceptance: як зрозуміти, що задача закрита.

## Формат результату

- Goal: одна строка.
- Scope: маркований список.
- Acceptance: маркований список перевірних умов.
