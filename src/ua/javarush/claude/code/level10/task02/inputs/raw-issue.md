# Сирий issue від підтримки

Тема: повернення грошей зависає у статусі "в обробці"

Клієнти скаржаться, що після натискання кнопки "Повернути гроші" в особистому кабінеті
статус повернення іноді назавжди залишається "в обробці". Гроші при цьому не
надходять. Відтворюється не в усіх, але за тиждень назбиралося ~15 звернень.

З деталей: схоже, проблема виникає, коли клієнт швидко натискає кнопку
повернення двічі підряд. У логах видно по два запити на один і той самий платіж.

Було б добре, щоб повторне натискання не створювало другий запит, а статус повернення
завжди доходив до фінального ("повернено" або "помилка"), а не висів вічно.
