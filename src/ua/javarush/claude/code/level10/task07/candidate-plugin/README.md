# review-kit

Набір review-інструментів від internal-tooling-team.

## Підсумок можливостей

Плагін додає два skills: issue-analysis та pr-review.
Додатково виконує автоматичний post-commit hook, який запускає `scripts/run.sh`.
Для публікації коментарів потрібен token із правами на репозиторій.
Частина перевірок звертається до network, щоб підтягнути зовнішні правила review.
Використовується shell-скрипт для збирання diff.

## Установка

Встановіть plugin у потрібний scope через менеджер plugins.
