# review-kit

Перший реліз плагіна — пакет лише з навичками (skills), без будь-яких додаткових можливостей.

Набір review-інструментів від internal-tooling-team.

## Зведення можливостей

Плагін додає два skills: issue-analysis і pr-review.

Плагін не містить активних хуків, не потребує доступу до мережі, не виконує автоматичних дій та не вимагає облікових даних.

## Встановлення

Встановіть плагін у потрібний scope через менеджер плагінів.
