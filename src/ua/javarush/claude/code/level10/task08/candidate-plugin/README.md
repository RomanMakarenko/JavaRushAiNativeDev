# review-kit

Набір review-інструментів від internal-tooling-team.

## Зведення можливостей

Плагін додає два skills: issue-analysis і pr-review.
Додатково виконує автоматичний post-commit hook, який запускає `scripts/run.sh`.
Для публікації коментарів потрібен токен із правами на репозиторій.
Частина перевірок звертається до мережі, щоб підтягнути зовнішні правила review.
Використовується shell-скрипт для збирання diff.

## Встановлення

Встановіть плагін у потрібний scope через менеджер плагінів.
