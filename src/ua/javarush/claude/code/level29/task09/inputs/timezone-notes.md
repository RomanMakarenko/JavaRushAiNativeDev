# Чернеткові нотатки щодо нормалізації часу

## Проблема
Поле `charged_at` зберігає локальний час сервера без явної часової зони. Після перенесення частини
сервісів в інший регіон звіти щодо платежів почали розходитись: одна й та сама подія
показується в різний час.

## Чого хочемо
- Зберігати час подій в UTC.
- Не ламати наявні звіти, доки новий шлях не перевірено.
- Мати можливість відкотитися, якщо щось піде не так.

## Ідеї (сирі, не план)
- Додати окремий стовпець для UTC-часу.
- Якийсь час писати в обидва поля.
- Поступово перевести читання на новий стовпець.
- Коли все стабільно — прибрати старе поле.

## Обмеження
- Жодних незворотних кроків без резервної копії.
- Спочатку все перевіряємо на test data / staging, не на проді.
