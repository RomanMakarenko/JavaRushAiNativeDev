# Нотатки до випуску — цільове оновлення payments-service

Готуємо пілот з оновлення стека. Нижче — витяг з upstream release notes,
який потрібно врахувати під час планування міграції.

## Spring Boot 2.7 -> 3.x (шар фреймворку)
- Базовий пакет зріс: `javax.*` замінено на `jakarta.*`.
- Піднято мінімальний baseline до Java 17.
- Частина класів auto-configuration переїхала; ламаються старі імпорти.

## Jackson 2.13 -> 2.15 (шар залежностей)
- Запроваджено ліміт довжини рядка під час парсингу (StreamReadConstraints).
- Змінилася поведінка за замовчуванням для деяких десеріалізаторів.
- Версія зараз приходить транзитивно і ніде не закріплена.

## Java 8 -> Java 21 (шар виконання)
- Видалено застарілі GC-прапорці, змінюється поведінка за замовчуванням.
- Sealed classes, pattern matching доступні на цільовому рантаймі.

## Gradle 8.7 / wrapper (шар збірки)
- Збірка тягне дистрибутив із `gradle-wrapper.properties`.
- CI поки збирається лише на одній версії Java.
