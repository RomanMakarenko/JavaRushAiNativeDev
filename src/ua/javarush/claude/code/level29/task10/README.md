# reports-utc-migration

Навчальний проєкт міграції часу звітів до UTC. Локальний pilot завершено.

Після pilot потрібен handoff-документ `POST_MIGRATION_NOTES.md`, який збирає в одне ціле
картину змін і посилається на вже готові артефакти:
- `ROLLBACK.md` — план відкату;
- `MIGRATION_VALIDATION_REPORT.md` — звіт про перевірку feature parity.

Документ не має дублювати ці файли повністю — лише посилатися на них.
