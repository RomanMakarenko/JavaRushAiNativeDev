# MIGRATION_VALIDATION_REPORT — звіт про перевірку міграції

## Що перевіряли
Відповідність даних між legacy-полем `reported_at` і новим `normalized_ts_utc`
після backfill на test data.

## Методика
- Вибіркова звірка 500 випадкових записів: перерахунок `reported_at` в UTC збігся з `normalized_ts_utc`.
- Порівняння щоденних агрегатів звітів за останні 30 днів — розбіжностей немає.
- Прогін contract-тесту на читання звітів із увімкненим прапором UTC.

## Результат
- Feature parity підтверджено на test data.
- Відоме обмеження: записи старші за 2 роки не входили до вибірки.

## Оточення
Локальний PostgreSQL-контейнер, production не зачіпався.
