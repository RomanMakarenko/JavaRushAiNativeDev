# Сфера пілоту: міграція на Boot 3 (read-only)

- Цільовий модуль: `reports`
- Режим пілоту: read-only (лише читання звітів, без запису в БД)
- Мета: перевірити сумісність модуля reports зі Spring Boot 3 на обмеженому зрізі
- Поза межами сфери: модулі billing, auth, будь-які write-операції
- Тип пілоту: запускається в окремому worktree, deploy у production не виконується
