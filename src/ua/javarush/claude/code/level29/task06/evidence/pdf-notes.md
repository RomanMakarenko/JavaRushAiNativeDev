# Нотатки з ручної звірки PDF

Звіряв експорт monthly report у PDF (кнопка "Export to PDF" на дашборді).

- Шапка, період і підсумкові суми в PDF збігаються з JSON response.
- Таблиця категорій у PDF відображена коректно, порядок рядків той самий.
- НЕ перевірено: CSV-експорт того ж звіту (поза pilot scope цієї ітерації).
- НЕ перевірено: локалізація чисел для валют, відмінних від EUR — звірка робилася лише для EUR.
