# Короткий виклад щодо evidence

Спостережувана поведінка: під час оформлення замовлення промокод зі знижкою застосовується
двічі, якщо користувач натискає кнопку «Застосувати» повторно до відповіді сервера.
Підсумкова сума замовлення зменшується на подвійну величину знижки.

Що вже відомо:
- Відтворюється на checkout flow модуля `commerce-checkout`.
- Поріг і тип знижки надходять із конфігурації, схема бази не змінювалася.
- Логи показують два послідовні виклики `applyPromoCode` з одним і тим самим кодом.

Чого поки бракує:
- Де саме має бути захист від повторного застосування — UI чи сервер.
- Чи вважається повторне натискання багом UI, чи має блокуватися на сервері.
- Який статус має бачити користувач після застосування промокоду.
- Що вважати успішною перевіркою після виправлення.
