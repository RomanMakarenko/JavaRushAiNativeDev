# DoD Review — Task 05 (trim-fix)

Дата: 2026-06-21  
Review базується на реальному `git diff` робочого дерева.

---

## Scope

Зміна в `OrderLabelService.normalizeLabel(String)`: додано виклик `.trim()` перед поверненням рядка. Базований на [issue](inputs/issue.md): зайві пробіли в label призводять до дублікатів у списку замовлень.

```
src/main/java/com/example/orders/OrderLabelService.java  | 2 +-
1 файл змінено, 1 рядок додано, 1 рядок видалено.
```

Інші файли (тести, конфігурація, API) не зачеплені.

## Open risks

- **Немає тестового покриття trim-логіки.** Зміна працює коректно за javadoc `String.trim()`, але без тесту регресія (наприклад, випадкове видалення `.trim()` при рефакторингу) залишиться непоміченою.
- **Gradle-оточення не перевірено.** Компіляція та проходження тестів у повному проекті не верифіковано.

**NOT_DONE**

Пункт DoD №3 (тести на trim-поведінку) не виконано. Для переходу в `DONE` необхідно додати тести, що перевіряють:
- обрізання початкових пробілів;

- обрізання з обох боків;
