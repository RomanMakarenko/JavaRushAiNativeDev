## Goal

Покупець у вітрині Commerce OS має бачити бейдж знижки `0%` для товару
з нульовою знижкою, а не порожнє місце. Додатні знижки (наприклад `10%`,
`25%`) мають відображатися як раніше. Завдання залишається точковим bugfix:
виправляється лише некоректна перевірка значення, без переписування компонента.
