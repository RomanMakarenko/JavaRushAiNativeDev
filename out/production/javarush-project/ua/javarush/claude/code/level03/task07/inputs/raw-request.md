# Сирий запит

Від продуктової команди Commerce OS.

> На сторінці refund detail оператору не вистачає короткого пояснення, чому
> повернення потрапило на ручну перевірку. Потрібно додати новий текстовий блок із цим
> поясненням на сторінку деталей повернення.

Обмеження з обговорення:

- Бекенд-контракт змінювати не можна: дані для тексту вже надходять у наявному
  payload refund detail.
- Це зміна тільки на боці сторінки деталей повернення.
- Платіжну інтеграцію, авторизацію і схему БД чіпати не потрібно.
