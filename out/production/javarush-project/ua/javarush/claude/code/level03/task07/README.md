# Робочий простір завдання — примітка щодо меж для refund detail

У цьому завданні потрібно оформити межі роботи до початку будь-яких правок коду.

## Що дано
- `inputs/raw-request.md` — сирий запит на новий текстовий блок на refund detail.

## Що зробити
1. Відкрийте Claude Code в корені проєкту.
2. Виконайте `/clear`, щоб почати з чистого контексту.
3. Попросіть Claude створити `submissions/BOUNDARY_NOTE.md` із секціями
   `Scope`, `Non-goals` і `Affected area`.

## Межі
- Кодові файли проєкту в цьому завданні не змінюються.
- Документ описує межі, а не реалізацію по рядках коду.
