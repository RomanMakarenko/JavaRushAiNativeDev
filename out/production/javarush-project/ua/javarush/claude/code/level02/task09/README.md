# Commerce OS — робоча папка

Локальний workspace сервісу повернень Commerce OS. За локальний запуск відповідають
`docker-compose.yml`, `.env.example` і скрипт `scripts/run-local.sh`.

Після короткої сесії фіксуємо usage-awareness як окремий крок: дивимося,
скільки контексту і вартості з’їла сесія, і записуємо один висновок для
наступної ітерації.
